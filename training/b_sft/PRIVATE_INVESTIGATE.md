# 私有调查：当前实现与教学审查

本页描述 `social-private-investigate-per-player-v1`。旧公开、共享额度版本及其数据保留用于复现，不与新版 gold 混用。

## 已实现的规则

- 每位玩家整局一次；一人使用不扣其他人的额度。
- 调查消耗当前提案机会，承诺不变，保持正常轮转。
- 查询者、被查询玩家和 goal 公开；答案仅由环境向查询者返回。
- 答案始终为真实偏好。选错目标是调查了不值得调查的偏好，不是环境提供假信息。
- 允许查询其他玩家已知或无关的偏好，照常消耗回合及额度；不按 teacher 的 belief 过滤合法目标。不能查询自己。
- 不新增随机回答、查询失败、撒谎机制或伙伴类型。伙伴仍自身收益优先、并列后利他、仍并列均匀随机。

实现：`social_private_teacher.py`。`PrivateInvestigationRules.step` 接收环境真值并私有交付；`observation` 返回指定玩家可见状态。模拟树的 `_apply` 仅记录公开查询，答案以世界确定的私有观察进入信息集；它不是对玩家交付答案的环境入口。

## Solver 的信息边界

私有答案不再产生公共答案分支，也不全局缩小 world support。每个公共行动节点内部，玩家按“自身偏好 + 自己历次查询的答案”划分信息集。看不到答案的玩家在无法区分的世界中采用相同动作分布；公开后续行动仍可改变其 belief。该结构保留公开行动历史及私有观察的记忆。

推演、行为似然、B 标签和 P 动作价值使用同一个固定选定策略。默认从均匀策略开始，同步更新最佳回应；不收敛、循环或超出资源限制均不输出标签。零概率反事实信息集沿用初始先验并条件化于自身偏好及自身收到的答案，不使用实际隐藏世界回退。这是明确的参考模型约定，不是唯一均衡证明。

`PrivateEpisode.belief` 必须指定 observer；`choices` 和 `belief` 都要求完整的本人查询记录，不能把别人的答案塞进来或省略自己的答案后伪装成未知。`PrivateEpisode.observe` 更新公共行为证据，不接收公开 revelation。

## 已生成的教学检查点

运行：

```bash
/private/tmp/social_native_tools_venv/bin/python -m training.b_sft.debug.audit_private_teaching --out <新的输出目录>
```

首批产物：`new/local_data/social_runs/private_teaching_v1/`，8 个开发检查点（B 5、P 3），不是 8 个独立游戏，也不是已接入 optimizer 的训练集。

- 两个私有答案分支：调查者收到 want/avoid 后更新 B，并分别选择不同交易。
- 第三人没有收到答案：保持不确定。
- 第三人观察到调查者随后按 teacher 自主提出的不同报价：更新为不同偏好。
- 最后一次提案还可调查：查询收益 0，最佳普通交易期望收益 1。

结果利用题中 risky 交易在两种类型下自身收益 2/0，safe 交易为 1/1。两个分支的 P 正确集合不相交，沿用双层 0.1 容差。环境逐边重放、独立 goal 合取/收益计算、所有节点续局价值对照、所有导出 gold 的原生工具提交评分均通过。

教学中的查询及其后的中间 PASS 是明确标记的合法 setup。查询发生后还有其他玩家的正常轮次，但这些早期 setup 不作为自主行为证据。这批题证明结果利用与后续证据更新，不证明从更早的查询决策开始该动作最优。P 直接收到当前 belief；B 的直接答案更新与行为反推分开标记，不把前者当成后者已经掌握。

## 完整查询起点的本轮结果

精确配置及资源限制见 `full_chain_probes.json`。

- 两目标、每人一个 commitment 选择的小残局，保留调查者下一次提案和所有中间玩家决策：56,259 节点，8 次同步更新收敛。但根部 11 个合法动作全部并列，自身期望收益均 1.5。可以作协议练习，不能作为有区分力的动作选择监督。
- 原来的双选项交易残局，从查询前开始：先超过 80,000 节点；增加到 300,000 节点、50 秒预算后仍触发时间限制。两次均未生成标签。

这不是基础模型不可训练的证据，也不是要求查询必须唯一最优。要补的是有若干好动作、也有坏动作的低难度选择题，同时控制完整求解成本。简单报价能直接提供证据的场景可以保留；多个目标收益重叠或相关、一个 ACCEPT/REJECT 不能单独确定偏好，适合放在后续难度。

## 验证与剩余工作

5 项新测试覆盖真实私有交付、个人额度、冗余目标、信息隔离、间接推断、末轮成本、完整信息独立逆推及私有题面；连同原公开 teacher、原课程回归共 22 项相关测试通过。

尚需完成：

1. 更早查询决策的低难度、有区分力教学题；不强求唯一正确，保留所有并列/近优动作。
2. 重叠 incentive 下的信息不完全报价、目标选择、等待时机及多隐藏偏好课程；目前只有一个主要结果利用结构。
3. 大树的计算开销及同步策略迭代的收敛问题；不能用全知替代、强制中间玩家 PASS 或偷偷缩短 horizon 来解决。
4. 一般 P 输入要足够说明各伙伴知道什么；首批通过明确公共查询历史及私有结果满足小案例需求，通用复杂输入仍需审查。
5. 生产 self-play runner 和 optimizer 尚未接入这个新版本。教学构造仅用于 B/P；self-play 必须按正式随机生成机制开局、自主互动、计算真实 outcome reward，不能直接使用教学目录或 teacher gold。

本轮没有远程上传、模型调用或训练。后续仍由助手提供命令，用户执行后再下载分析。
