# 原题型内的难度梯度

构建：`python -m training.social_mixed.build_difficulty_curriculum`。

只重组已认证母题，不新增辅助题、不提供中间答案、不改原始场景或canonical标签。每个母题保留O/B/P三视图，split不变；59个不合格P仍不能训练。

- 基础：剩余机会<=1、目标<=2、B/O历史事件<=2。
- 中间：剩余机会<=2、目标<=3、B/O历史事件<=4，但不属于基础。
- 组合复杂：其余场景。

P历史为审计字段，不参与P难度。母题分层取三个视图中最高层级，O/D共享这个分层；层内继续按历史、目标交叉和动作数排序。它是可复核的结构课程，不是实测难度证书。低层B也可能难，不能据此将模型失败标为异常。

训练母题：基础97、中间75、复杂201；其中P合格母题为97/67/150。validation按现有split保持：基础0、中间91、复杂33。当前validation没有基础层，不能声称覆盖完整梯度，也不能为凑数将训练母题移入验证。

采样实际读取task_difficulty.describe，使用同一分层规则；此目录任务文件是无损审阅分组，不是绕开主manifest的独立bank。全局低曝光优先于层级，难题不会被永久排除。关系对两端都轮到才采，完整对可能跨层，因此不保证每一组严格按层级递增。

B评分现为b-near-top-0.1-v1：set必须正确；接近最高值的favored或undetermined可接受。canonical gold/posterior仍保留，strict_correct独立报告；P认证和mask未改变。
