# 基于实际 B 学习轨迹的候选库

独立候选，未切换现有训练入口。只使用训练 calls 作选题依据；不读取 validation 表现选题，不改变验证题、原始库或 O/P 标签。保留先简短解释再提交、原奖励、exact support 与 favored 容差。默认使用原 paired_requests，不额外启用上一版语义澄清，以免同时改变两个因素。

## 逐题核查

合并 D 的 0–124 步，按 task ID 的曝光次序比较，每次 8 次生成。200 道 B 中：

- 11 道至少三次曝光，正确数不下降且末次高于首次，至少两次实际产生正负 task advantage。
- 其中仅 7 道在排除截断/无效后的条件正确率也不下降且有净提升。其余 4 道不作为语义学习成功的强证据，不加权。
- 另有 13 道至少两次正负对比、末次正确数更高，但只有两次曝光或中间存在波动。
- 25 道每次均为 8/8 正确；20 道三次均无正确回答。

严格的 7 道并非一种标签：包括保留三种可能、保留 want/neutral、排除到 want、由公共条件确定 neutral。代表性轨迹：

| 操作 | task ID 前缀 | 正确数/8 |
|---|---|---|
| 单行为下保留不确定性 | 1ff94f17 | 4→5→5 |
| 单行为下部分排除 | 5aab9fc4 | 0→1→2 |
| 公共条件约束 | c6441011 | 5→5→7 |
| 先验与公共条件下保留可能性 | 6ca04e77 | 3→3→5 |
| 提议及拒绝后的判断 | 5ccf8b51 | 0→1→3 |

完整正确数、截断数、条件正确率及混合组标记在 task_audit.json。这些是有限采样下的观察，不是已证实的掌握度或因果结论。

## 候选库与曝光

仍为 **200 道 B**：保留原库 180 道，用 20 道桥接替换持续全错的 20 道。全错原题保存于 hard_diagnostic.jsonl，未删除原始资料，也没有标成新的独立验证集。

每题相对采样权重：

- 严格 7 道语义改善题：2。
- 13 道较弱改善证据题：1.5。
- 25 道始终全对题：0.25，保留复习，不完全取消。
- 其余保留题和新桥接题：1。

权重是保守候选设计，不是经实验找出的最优比例。`b_learning_sampling.select(tasks, counts, size=4)` 按累计曝光/权重轮转，每次不重复同题；保存 counts 即可恢复。它不在训练中追采当前有奖励的题，不调整任务损失权重。当前 D trainer 尚未调用这个 sampler，不能只换 tasks 文件就认为权重已生效。

## 桥接如何降低难度

1. **18 道去重后的无行为证据 B**：从 20 道难题的原生偏好、目标与公共条件重建场景，清除原有自愿行为与私人调查结果。设为一个原生完整轮次，其他席位由明确标注的 imposed PASS 消耗机会，ego 处于最后提议点。不是把原历史删掉后照抄标签：重新计算 teacher、偏好支持与 favored。此层练习“已知事实/先验 → 可能集合及偏向”，暂不要求反推策略。
2. **2 道单行为 B**：从已有通过审计的 progressive **train** 场景选择一个 identifying、一个 uncertain；其余未入选桥接存于 bridge_reserve.jsonl，不占当前采样。原保留库已有的单行为题仍存在。
3. **完整行为推断**：保留具有真实学习信号的单行为、多事件原题；最难原题只用于之后检查桥接能否迁移，不自动恢复曝光。

bridge_links.json 记录每道难题与基础题/单行为候选的对应。单行为桥接是操作层面关联，不声称是同一历史的严格反事实配对。新的 B 基础题仍有原生完整状态和同一种提交接口，没有新增辅助任务、教师解释或数值 belief 输出。

**桥接通过了标签与请求的离线校验，未经过模型可学习性测试。** 降低结构复杂度不等于已经产生正负 advantage。

## O/D 对照边界

原有 O/P 未删改；新增 20 道 B 尚未生成对应 O/P 配对。因此这是 B 修订候选，不能直接宣称是 O/D 等数据条件的正式实验库。正式接入前需固定新增场景的 O 对照和任务曝光预算；不要用修改后的 D 与旧 O 作严格单变量比较。

## 复现与验收

```bash
python -m examples.social_mixed.b_learning_candidate_v1.build
python -m unittest examples.social_mixed.b_learning_candidate_v1.test_candidate -v
```

build 读取本地两份训练 calls 压缩包，重新计算逐题分类及原生桥接标签，不调用模型、不启动训练。审计脚本同时更新 short_interaction_v1 下的 advantage 审计。测试覆盖 200 题 gold 评分、先解释契约、训练 split、排除名单及采样比例。
