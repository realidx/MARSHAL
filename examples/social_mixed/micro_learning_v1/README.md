# 独立微型学习实验 v1

目的：在40次更新内重复练习有历史学习证据的少量题。不是正式O/C/D对照，不以CalBench选择题目，不声称已保证泛化。

从旧BP完整主链及旧D逐题calls统计筛选：至少3次曝光；首次正确不超过3/8；末3次至少75%正确；至少2次有效advantage对比。排除已知prompt/gold冲突的7ba55…B。当前修复D只有两次曝光的B不入选；仅一次曝光的O/P也不冒称已证明可学习。

保留历史实际request、工具和对应task/teacher，不生成新prompt、不改标签、不拿验证题训练。旧P包含历史、完整信息、调查等混合接口：它不是当前无历史定性P；不能把本实验当成恢复正式P接口的授权。B仍保留原有解释后提交要求。筛选使用后期训练表现，因此是探索性训练集选择，不是独立测试。

每步每题独立采8个回答，40步每题曝光40次、320条回答。组内单题标准化，不能跨题混算advantage；每题等权，不额外按B/O/P域均分。沿用协议错误独立惩罚和KL的训练逻辑；全错组依旧不能凭空产生任务梯度。step0先记录Q0表现，后续记录逐题正确/截断/有效组，而不是仅记录全库平均。

`tasks.jsonl`保存题目、冻结请求与完整历史曝光证据；`examples.jsonl`保存原始正负回答样例；`schedule.jsonl`给出40步计划；`manifest.json`记录哈希和全部历史回答重新评分数量。`dataset.batch(update)`输出带独立seed的请求，`dataset.score`使用对应原始评分契约。构建命令：

```bash
PYTHONPATH=. python examples/social_mixed/micro_learning_v1/build.py
```

该目录未替换当前任何训练入口，未提交GPU任务。已有训练pipeline不能直接把本文件当普通tasks.jsonl读取，需要使用此处冻结request接口；不能静默重新渲染。接通时应设置40更新上限，预算应足以完成40步，并以真实tokenizer检查prompt长度。历史学习趋势不保证这次40步复现；训练题正确率提升不能独立证明能力迁移。

## 已接通独立训练入口

```bash
bash examples/social_mixed/start_micro_training.sh h200-141
```

该命令在训练机提交任务；本地修改不会自动提交。入口设置40更新上限，
每10次更新保存与静态验证，保留4个checkpoint（零起始文件编号9/19/29/39）。
每步13题×8回答，每题等权。响应token预算4259840是40×104×1024安全上限，
正常以40步结束；cosine学习率仍按实际token进度计算，不承诺40步衰减到最低。
只使用冻结请求，不调用当前B/P prompt重渲染；提交前做真实tokenizer长度检查。
验证沿用现有静态O/B/P，不新增交互评测。训练calls用于逐题学习曲线。
已有入口要求干净已提交源码；本地CPU回归通过不等于GPU验收。
