## 核验与边界

- 核对全部旧任务的input、teacher、split、p_train_eligible未改变。
- 1935个视图全部实际渲染，所有B/O标准答案通过实际评分器。
- 每母题恰好三个视图、同一split；共同池整母题准入。
- 新旧场景碰撞检查忽略历史、先验、偏好和轮次，按参与人数、动作空间、目标关联与binary/linear检查；冲突的新family整族隔离。
- 该检查不是玩家／动作重命名后的完整同构认证。旧库本身有4个粗粒度场景签名跨split，保留原划分并报告，不能宣称结构完全留出。
- 目前沿用旧验证库，因此共同validation中没有新极简层。可以检测旧能力保持，不能单独检验新简单层的泛化。
- 尚未完成真实Q0学习难度测量，也未接入正式bank加载器。扩大总库不代表训练时应等概率混入全部题；课程及曝光预算需基于可学习性核查后确定。
