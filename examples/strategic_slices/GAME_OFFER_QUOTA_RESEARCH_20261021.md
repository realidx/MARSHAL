# 报价机会限制：保持调查与偏好不变的第一轮研究

当前决策：**先研究提出OFFER立即消耗个人报价额度；调查机制不改，dependent preference暂不加入。**
此前的免费调查和合同菜单都是独立设计记录，不是本次采用的生产规则。

状态：独立研究代码已实现，7个父游戏各做无额外额度限制/每人一次额度的配对，共14次完整终局求解并认证。
只运行CPU，无LLM、训练或题库更新。active仍是`terminal-node-regret-grpo-readable-v8`；未将本机制接到旧prompt、评分或checkpoint。

## 1. 本次唯一物理规则变化

| 项目 | 本次口径 |
|---|---|
| 报价额度 | 诊断取每名玩家整局1次，和无额外额度限制比较；不是已确定的生产默认值 |
| 扣除时刻 | 提出OFFER、生成pending offer时立即扣除；早于ACCEPT/REJECT |
| 接受/拒绝 | 均不退还、不再次扣除；回应者不消耗自己的报价额度 |
| 额度耗尽 | 禁止新的OFFER；仍可PASS、使用未用调查、回应其他人的报价 |
| 回合消耗 | 保留原生机制：OFFER及其响应共同完成一个提案回合；PASS、INVESTIGATE各占一个提案回合 |
| 调查 | 不改：每人整局1次，仅proposal阶段；目标/行为公开，真实答案私有并累计保留；允许查询已知/无关目标 |
| 收益 | 保留原生linear/binary目标效用，没有额外报价扣分、拒绝罚分或调查奖励 |
| 合同 | 保留完整原生承诺向量菜单、单边报价、每次max_changes限制；没有增加项目互斥或接受即结束规则 |
| 偏好 | 配对内同一support和prior；只纳入固定单元格+变量单元格的笛卡尔support，未添加逻辑依赖 |
| 玩家规范 | 全员同一终局求解；仅响应自身预期终局效用平局时最大化其他玩家效用总和 |

这是独立的报价预算，而不是给原有回合预算改名。**一轮游戏每人本来只有一次提案机会，额度1不产生额外限制。**
本轮对7个父游戏各做了一轮控制，完整行动树均未减少合法动作。主研究因此采用两人两轮。

## 2. 样本、求解与测量

预先声明6个紧凑控制父游戏，另加入已有[两人原生调查价值样例](fixtures/native_acquisition_two_player.json)。
控制包含每人2次提案机会、P0两个原生行动/P1一个、3个binary目标，P1仅一条偏好可变、其余固定。
已有样例保留原5个linear目标、原先验和原生行动结构。没有跨父游戏把这些结构差异当报价额度的因果效果。
本轮是便利样例诊断，不是现有题库的随机抽样或生成器产率评估。

配对内raw完全相同，只变`offer_limit=None/1`；每个变体独立重新求解，包含对手适应和profile选择的变化。
枚举到真正终局，无非终局截止叶、近视伙伴或逐个隐藏world的完全信息标签。
采用现有一般和候选搜索，独立检查自身完整策略偏离、局部支持、响应社会平局和信息集一致性。
14/14通过，numerical epsilon=1e-8；报告最大自身偏离增益为0，不声称唯一或精确均衡。

诊断使用完整收益向量处理响应平局，并与参考完整best response核对。
**这没有修复生产v8 own-only评分缺口**，研究测量不调用该标量评分来冒充已对齐。

分别报告：

1. 初始节点最佳调查与最佳非调查行动的Q差，后续可使用所有合法行动。
2. 同一伙伴profile下，自身允许/禁止全部后续调查的最优终局收益差；不是重新求一个“全体禁止调查”的均衡。
3. 对有信息的最佳查询，强制相同查询行动后，真实答案与屏蔽答案的后续最优值差。保留prior、物理行动/成本和伙伴profile。

所有可达首个proposal信息集均测量；答案消融仅覆盖有信息的最佳查询，未测量的其他查询不能记为信息价值0。

## 3. 结果：额度施压生效，但尚未增加调查优势

| 初始节点指标 | 无额外报价限制 | 每人一次报价 |
|---|---:|---:|
| 6个紧凑控制中，调查有严格首步优势的父游戏数 | 0/6 | 0/6 |
| 6个紧凑控制中，允许自身调查的收益增益 | 全部0（容差1e-8） | 全部0（容差1e-8） |
| 已有原生样例：最优终局收益 | 1 | 1 |
| 已有原生样例：调查相对最佳非调查首步优势 | 0.25 | 0.25 |
| 已有原生样例：允许自身调查的收益增益 | 0.25 | 0.25 |
| 已有原生样例：相同查询下答案价值 | 0.214286 | 0.107143 |

已有样例的答案价值降低发生在两个重新求解的profile间，包含伙伴适应和选择效应；
不能把这一差异当作固定对手下的纯信息实验，更不能因此断言报价限制一般都会削弱调查。

**报价额度不是没有作用。** 例如`compact_1_slot_0`，P0最初报价的三个完整native target如下：

| OFFER内容（目标承诺向量） | 无额外限制的Q | 一次额度的Q |
|---|---:|---:|
| P0=[0,0], P1=[1] | 0.666667 | 0.453704 |
| P0=[0,1], P1=[0] | 0.666667 | 0.423469 |
| P0=[1,0], P1=[1] | 0.666667 | 0.666667 |
| PASS | 0.666667 | 0.666667 |

在各自完整profile下，前两种报价确实承担了失败后不能再次报价的风险，但仍有第三种报价和PASS策略达到同样最优值。
所以“某些试探报价变差”不等于“最好的不调查策略变差”。本轮没有建立额外调查价值。

查询频率也不能替代这个检验：同一控制中，初始参考调查概率由0.375变为0.6，
但首步调查优势和答案价值仍为0。这来自同分策略及后续profile变化，不能写成调查变得更必要。

完整树节点数也下降：紧凑控制22961→8348，已有样例143014→44590。
这是这些两人局的枚举规模结果；尚未验证三人多轮的规模或收敛改善。

## 4. 当前判断与后续顺序

本轮确认了“提出报价立即消耗额度”的正确执行和实质机会成本；**尚未确认它足以改善调查学习信号**。
不能据7个便利样例否定机制，也不能以已经增加部分报价风险为由宣布解决。

继续保持dependent preference暂缓，先检查：

- 不调查最优策略是否通过安全/单边报价保留收益；PASS后能否依靠知情伙伴主动报价。
- 当自身额度耗尽时，伙伴报价是否仍能完成原本目标；应保留这一合法渠道再完整比较，不能暗中禁用伙伴报价来放大调查收益。
- 更广的独立偏好、已有原生目标结构中，额度能否让“最佳不调查完整策略”严格变差，而不只是使少数坏报价更差。

本轮没有确定生产报价额度，也没有修改调查、合同可行性、偏好依赖、训练算法或prompt。
三人多轮未运行，扩大题库/重算C/S/D/重新训练均未运行。
