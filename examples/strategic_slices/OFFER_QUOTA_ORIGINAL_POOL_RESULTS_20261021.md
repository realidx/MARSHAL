# 原100个父游戏：提出OFFER扣除报价额度的整批结果

**本轮在原100父游戏上完成检查：100个旧profile重新认证通过；70个一轮局与原游戏等价，29个两轮局求出新的认证profile，1个两轮局仍未认证。**
没有替换、删除或新增父游戏。有效配对99局中，包含“调查严格更优且答案本身有用”局面的父游戏从6个增至16个，新增10个。
29个受影响的有效配对中，开局合法报价的平均regret全部上升，28个父游戏的开局最优动作集合变化。
这支持继续完善报价额度版本；当前保留独立偏好，不添加dependent preference。

本轮只做CPU机制研究。没有模型调用、训练、GPU实验、prompt修改或新题目D测量；没有证明slices训练效率优于SP。
生产active仍为v8，已知响应社会平局评分缺口仍未在生产代码中修复。

## 1. 研究对象和唯一物理变化

使用active v8所登记的`strategic_slices_oracle_consistent_candidates_v4/parents.jsonl`原100父游戏。
父游戏raw、ID、split、目标、行动、轮换顺序、偏好support和prior逐项保留。
原split为train 63、validation 12、test 25；原覆盖为30个两人两轮、20个两人一轮、50个三人一轮。
全部原reference文件hash核对通过，原profile身份保持不变。

新增规则：每名玩家每局最多提出一次OFFER，**提出时立即扣除额度，早于回应；ACCEPT/REJECT均不退还**。
回应别人的OFFER不扣自己的额度。耗尽后仍可PASS、使用尚未使用的INVESTIGATE和回应报价。
不额外扣终局utility分数；没有接受即结束、合同互斥或新合同菜单。

调查保持原机制：每人整局一次、仅proposal阶段、消耗一个提案回合，目标/行为公开，答案私有并累计保留。
允许查询已知/无关偏好这一原规则也未改。所有原偏好support验证为逐目标笛卡尔积，没有加入逻辑依赖。

每人只有一次proposal机会的一轮局，报价额度1不可能额外删除行动。
额度计数由既有公开历史和pending offer确定，不增加私有信息；原、新游戏的行动、信息集、策略和收益可一一对应。
因此70局明确记录为“等价复用原profile”，没有把它们冒称为70次新求解。

## 2. 求解、审核和剩余一局

全体玩家使用相同的终局策略求解和目标：自身预期最终utility优先；只在ACCEPT/REJECT自身平局时，最大化其他玩家utility总和。
保留完整原生行动枚举和真正终局，所有接受的新树非终局cutoff叶数为0。
接受标准为自身完整策略偏离增益不超过1e-8，另检查局部最优支持、响应社会平局、私有信息集一致性、每条状态转移和终局payoff。
这是一组被独立数值认证的参考profile，不是唯一或精确均衡证明。

- 原100个profile重新认证通过，最大自身偏离增益约`1.04e-10`。
- 新29个报价限制profile通过，最大自身偏离增益约`3.47e-11`。
- 4项额度/调查语义回归检查通过；每个新profile另做全树额度计数审核。
- 1局`c8fdc75802d43fb7a5b96676`保留为缺失结果：原profile通过，新规则下候选未通过完整认证。
  它仍在100局身份清单中，没有按零信息价值统计，也没有用旧profile充当新游戏标签。

所有失败和重试保留，按以下预先声明的顺序接受第一个通过完整认证的profile，**不根据调查收益选择profile**：

| 记录 | 数值搜索变化 | 结果 |
|---|---|---|
| full_pool_run_v1 | 100局；新求解90秒、joint evaluations 160、候选6、cell预算4096 | 70等价，27新认证，3缺失 |
| full_pool_retry_v2 | 仅3个失败局；240秒、joint evaluations 640 | 1新认证，2缺失 |
| full_pool_retry_v3 | 剩余2局；300秒、evaluations 1280、候选12、cell预算8192、sweeps 256、large-tree ordered sweeps 8 | 1新认证，1缺失 |
| full_pool_retry_v4 | 剩余1局；数值初始化改为公开固定的Dirichlet种子0/1/2；150秒/种子，采用首个认证结果 | 3个种子均未认证 |
| full_pool_retry_v5 | 剩余1局；把原认证profile按共同历史映射到新菜单，重归一化后作为数值起点；240秒 | 映射检查通过，新profile仍未认证 |

v4/v5是**数值初始化/选解协议变化**，不是仅增加预算。每版完整参数、命令、source、环境和失败原因均写入自己的`pipeline_snapshot.json`。
物理规则、先验、utility、调查机制、响应平局规范和接受精度在各次重试中不变。
v5仅复用搜索起点，全体玩家仍须重新优化并认证，没有固定近视对手、沿用旧Q或放宽认证。
该局的失败是当前求解器限制，不能推断不存在解。

## 3. 指标与结果

测量每位玩家在各自profile下**首个实际proposal机会**的可达信息集；同玩家的历史/私有类型按reach加权，玩家等权，父游戏等权。
这覆盖开局和较晚轮到的玩家，不是只测schedule的第一位玩家。

- 调查动作优势：最佳调查Q减最佳非调查Q，后续完整优化到终局。
- 调查访问价值：允许自身调查与禁止自身全部后续调查的最优终局值之差；伙伴保持同一profile。
- 答案价值：强制同一调查行动、保持物理状态/成本/prior/伙伴profile，只屏蔽该答案，再完整优化后续。
  本轮消融覆盖有信息的最佳查询；未测的其他查询不当作信息价值0。
- “真实调查价值见证”：同一可达信息集上，调查动作严格更优，且该最佳查询的答案价值也为正。阈值均为1e-8。

### 全部有效配对99局

| 指标 | 原规则 | 报价额度1 |
|---|---:|---:|
| 有严格调查动作优势的父游戏 | 7 | 17 |
| 有真实调查价值见证的父游戏 | **6** | **16** |
| 有正的“同一调查下答案价值”的父游戏 | 20 | 20 |
| 严格调查优势信息集的加权概率 | 2.30% | 6.75% |

真实见证新增10个、消失0个；新增父游戏均为原池非calibration父游戏，涉及5个family，不能当作10种独立机制。
剩余父游戏继续保留，不要求每题都调查。
这里“答案有用”的数量不变，但更多局面值得为信息花一个回合：信息获取能力没有增强，报价的试错机会变少。
不能把“调查动作更优”一项单独当作私有答案有用的证据，两种量已分开报告。

### 受影响的有效配对29局

| 指标 | 原规则 | 报价额度1 |
|---|---:|---:|
| 有真实调查价值见证的父游戏 | 1 | 11 |
| 加权平均调查访问价值 | 0.00431 | 0.01803 |
| 严格调查优势信息集的加权概率 | 1.72% | 16.92% |
| 初始合法OFFER的平均regret | **0.04248** | **0.36464** |
| 初始合法OFFER中非最优动作的平均比例 | 19.13% | 73.19% |
| 初始全部动作Q的平均跨度 | 0.09971 | 0.75754 |

报价regret对初始每个合法OFFER等权，再按初始私有类型prior和父游戏加权；**不是模型实际采样分布**。
29局的平均报价regret全部增加，28局初始最优动作集合改变。
这说明影响不仅限于是否调查，也使原先可无损试探的许多报价变成有终局损失的选择。
组内实际训练信号是否增加，仍需用最终prompt重新采样测量，不能由合法菜单统计代替D。

70个非约束局的所有机制指标保持一致。
配对中4个父游戏初始行动玩家在所选profile下的预期效用下降；结果包含伙伴适应与profile选择变化，不是跨所有均衡的效用上界声明。

## 4. 一个原池内的具体变化

父游戏`00b639b4d31702d4697bd057`，不是新造控制题。两人两轮，schedule为`[1,0,1,0]`。
玩家1在开局、自己的两项偏好均为want时：

| 选择/策略 | 原规则Q | 报价额度1下Q |
|---|---:|---:|
| 最佳INVESTIGATE | 1.833333 | 1.833333 |
| 最佳直接OFFER | 1.833333 | 1.759259 |
| PASS | 1.772727 | 1.711111 |
| 全程不调查的最佳策略 | 1.833333 | 1.759259 |

限制后，最佳调查明确领先最佳非调查行动约0.074074。
强制该调查但屏蔽答案，Q降至1.796296，答案本身贡献约0.037037。
两个差值定义不同，不能把整个动作优势都归因于答案。
该局的偏好support、prior、目标和调查成本与原游戏完全相同。

## 5. 验证/测试覆盖及实验含义

新增10个真实调查见证均出现在原train split。
有效配对train 62局中真实见证6→16；validation 12局、test 25局均为0→0。
验证/测试中的报价regret和动作集合仍有变化，但本次首个proposal测量没有得到严格的调查需求。
这限制当前held-out数据对调查能力的评估；不能用新增train见证宣称泛化改善。
本轮没有为了扩大正例而重划split、替换游戏或加入依赖偏好。

当前可以保留独立偏好，继续完善报价额度版本。正式训练前仍需要：

1. 为剩余1局得到合格的新profile，保留100父游戏对象，不自动删题。
2. 在新规则下重建受影响的slice入口/窗口、Q、C/S和selection；本轮是全终局机制诊断，**不是新的k=1/2/3 slice标签**。
3. 对齐生产响应社会平局评分；在独立新prompt版本中明确报价额度，并导出实际request样例。
4. 最终题面下重测D，再让SP/slices共享父游戏及规则，冻结两臂采样/预算/评测合同后运行训练。

当前旧100条训练slice覆盖56个train父游戏这一历史身份也未改；它们不是“原100父游戏”的替代对象。
本轮不改GRPO、reward、advantage、训练批次、生成参数或checkpoint。
