## 一个额外数学诊断：信息是否迫使当前选择改变

只看canonical分布变化会包括剩余平局切换。为解释私人答案组，另计算：

```
LB = sum_i w_i max_a Q_i(a) - max_a sum_i w_i Q_i(a)
```

i是同一公开节点、本人偏好和其余答案下，该答案不同的完整入口；w沿用原counterfactual质量。
遗漏该答案后，当前行动必须共享分布。LB假设当前动作之后恢复全部信息，因此是一个放松问题，满足：

```
0 <= LB <= 该组实际当前行动损失平均 <= 该组完整S平均
```

若LB为正，任何共用当前行动分布都会在某些答案情景付出代价，与canonical剩余平局怎么混无关。
LB为0仍可有未来S或模型困难；它不是完整S替代品，不是已采纳的筛选公式，也不保证跨reference稳定。
只对私人答案严格分组，不用物理骨架近似公共历史遗漏组；正值仍用既有1e-8数值分辨率。
[诊断版本说明](versions/candidate_qs_parent_review_v2_20261104/CHANGELOG.md)保留公式与范围。

### 观察1：非零相对Q本身几乎没有父游戏过滤能力

H2的31/31、A2H2的30/30、结构池的22/22都有至少一个相对Q变化场景。
因而“存在非零Q/S profile”太弱，不能直接作为优质父游戏验收标准。
同时这说明仅保留正own S也会丢失大量“最优选择可保持、次优差距受信息影响”的入口，最终仍需D。

canonical分布变化分别为H2 6,076、A2H2 14,185、结构池5,579个context，
但部分变化只在已允许的等价动作之间调整概率，不能按JS大小直接排序。
全own S为0但相对Q改变分别有12,662、22,538、12,509个context，不能直接认定有或无模型训练价值。

### 一个可读的当前选择例子

新结构池index1、node360023，P2已调查P0/G2。保留同一公开节点/本人偏好，其三个答案context权重各1/3。
只摘两个合法合同供说明，完整九行动Q保存在对应新labels及PARENTS诊断中：

| P0/G2调查答案 | 动作3：P2加自身事项、不要求P0新增事项 | 动作5：P2加自身事项、要求P0新增action1 |
|---|---:|---:|
| want | Q=2 | Q=1 |
| neutral | Q=0 | Q=1 |
| avoid | Q=0 | Q=1 |

知道答案时平均最优值4/3；忽略答案、共用当前选择时，九个动作中最佳平均值为1。
因此LB=1/3，实际平均当前损失和完整S也均为1/3。这里不是仅收益基准变化或任意平局混合。
例子仍相对于该保存reference，不证明上游调查严格必要或跨均衡唯一。

## 对父游戏制作和800入口的约束

以下是本轮审查使用的解释原则，不是已激活的接受率、阈值或配额：

- 按动作—目标结构、隐藏位置、已有信息、当前/后续影响分别查看，不仅看最大S。
- 原始正context数、物理骨架数、父游戏/geometry覆盖、reference访问质量分别报告；均不等于独立题目数或模型D。
- 既检查真实信息利用链，也保留无需调查及共同最优但次优差距变化的结构，避免总调查模板。
- 配对比较只用共同可测原游戏/完整结构对；不同获认证reference之间的关联不宣称隔离因果。
- 父题允许重抽，但需要依据观察结果讨论生成/接受规则并留痕；本轮不强制全want、不加dependent偏好或改额度。
- 正式100父游戏与800 train/validation分配尚待确定；不继承旧504/96/200，不提前测D或生成测试池。

## 建议下一轮制作父题的方向（待讨论，未激活）

1. 以目标结构覆盖作进一步生成候选的起点，重点寻找偏好答案使合同/伙伴收益排序真正交叉的结构；
   不只增加隐藏单元、行动或回合数，不用单个父游戏的大量相近历史补数量。
2. A2H2中62/78可保留为有价值的机制见证，但不能主导正式父池；需要把该决策结构扩展到不同目标图形与偏好抽样。
3. 不强制公开全want、不把shared-goal隐藏位置当必要条件，保留split/bundled及各计分的覆盖与无须调查对照。
4. 讨论验收时分别约束“真实选择敏感／后续信息需求”“相对Q改变但共同最优”“无须遗漏信息的规划”的来源覆盖。
   本报告不给出固定比例，不把LB>0升级为所有父游戏必须满足的门槛；最终仍要由训练候选D评估目标模型。
