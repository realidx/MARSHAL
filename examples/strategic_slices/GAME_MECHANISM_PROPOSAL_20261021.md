# 2026-10-21：先设计有独立调查价值的游戏，再设计prompt

状态：游戏机制研究提案，**未修改生产游戏、Oracle、题库、prompt、训练参数或active版本**。本轮按用户要求暂停prompt改版，先解决调查与报价试探的替代问题。现有v8及原始证据保持原身份。

## 1. 问题定位：报价确实是信息行动，但不等于真实偏好查询

INVESTIGATE返回指定偏好的真实want/neutral/avoid，答案私有，消耗一个提案机会。OFFER的ACCEPT/REJECT是公开的策略响应，取决于整份合同、自身最终收益、后续机会和响应平局规范；不是无条件返回某个真实偏好标签。

在一个只影响单目标、没有后续选择的报价中，want和neutral可能都接受，avoid拒绝。如果后续行动只需要分清“会接受/会拒绝”，精确区分want/neutral的额外信息没有决策价值。报价还可能同时实现收益，调查却只耗机会。便宜、可重复、几乎不限制后续行动的报价会成为低成本试探。

当前机制里的主要风险因素是：承诺没有通用资源互斥、允许单边新增承诺、拒绝没有额外损失、部分收益可加分离、后续机会足以补做、公开偏好锚点已经让很多最优行为不依赖未知值。这是有记录的结构假设，不是对每个因素已完成因果归因。

公开偏好关联也会帮助报价推理。若一个便宜offer的反馈已经识别全部相关类型，再加一条关联规律未必让调查更有价值。因此不应只靠“加入dependent preferences”或“降低S门槛”解决问题。

## 2. 仓库已有证据及其边界

- [旧v3池早期调查审计](../../new/local_data/strategic_slices_early_investigation_v1/summary.json)：100父游戏、8,357个可达首提案信息节点；2,573个调查/非调查平局，5,783个调查更差，仅1个微弱优势.0138533。该个优势在屏蔽答案后仍存在，不是调查答案的价值。这不是对当前v4的同一统计。
- [旧机制诊断](../../new/local_data/strategic_slices_mechanism_diagnostic_v1/conclusions.json)：6个便利抽取父游戏、249个免费单槽信息比较，只有3个正增益，最大.03661；5个选定两人父游戏甚至免费完整对手类型也不提高早期价值。仅降低调查成本不充分，但不能推广成所有游戏的定理。
- 当前原生规则并非完全不可能产生调查价值。[原生搜索记录](../../new/local_data/strategic_slices_native_acquisition_review_v1/summary.json)已有两个完整初态求解、独立复核的基本机制，后来扩展为6个校准family。三人原生例子S=.08333，两人例子完整终局S=.21429。它们说明存在正例，也说明无约束随机生成的覆盖不足；原型/先验变体不应当成大量独立机制。

## 3. 推荐的结构改变：稀缺资源上的合同选择

建议先围绕以下三个相互配合的要素建立可解的小型校准，再确定正式规则：

1. **有限、完整的合同选项。** OFFER提出真实可执行的项目合作方案，保留ACCEPT/REJECT，不让它变成免费回答偏好的问卷。
2. **资源或互斥约束。** 例如每人只有一份资源，只能投入一个项目；接受一项合作会失去其他机会。调查本身不分配资源，报价被接受则不可逆。不是任意加“报价惩罚”。
3. **有限但足够利用答案的机会。** 调查后必须能做至少一次相关决策，但不能有无限试错把所有类型都筛完。机会数是公开的游戏期限，不是事后由训练窗口截断的效用。

单槽调查仍只给一个真实偏好；公开的联合类型规律可以让这一个三值观察识别更多后续决策所需信息。保留普通报价的推理价值，并让某些局面最优调查、另一些局面最优直接报价。

## 4. 一个已精确验证的最小机制

这是一种**新的两人非对称议价模型**，不是当前BENAC-P轮换提案游戏的既有证书：A拥有两次提案机会，B回应合同。每次A可以PASS、提出X/Y/Z中的一个合同，或一次性调查B在某项目上的真实偏好。调查消耗一次机会，且最多一次；若最后一次才调查，没有剩余签约机会，收益为0。拒绝免费但消耗这次机会；接受一个合同即用完双方资源，游戏结束；两次机会用尽未签约则双方0。

B的联合私有类型为下表三种之一，先验各1/3。这个联合类型表是公共规则，实际类型只有B知道。

| B类型 | 对X的偏好 | 对Y的偏好 | 对Z的偏好 |
|---|---:|---:|---:|
| T1 | want (+1) | avoid (-1) | avoid (-1) |
| T2 | neutral (0) | want (+1) | avoid (-1) |
| T3 | avoid (-1) | avoid (-1) | want (+1) |

A签X/Y/Z的最终收益分别为1/2/2，公开且固定。B获得对应偏好的+1/0/−1。未签约为0。可用“一个基础目标，Y/Z各另一个A想要、B中性的附加目标”表达A收益2，避免必须发明新的偏好强度。

本原型的合法合同菜单是三个完整项目，**不包含任意部分承诺或新造菜单合同**；两次提案权都属于A，B拥有响应权。不能把这个不对称模型的数值结果直接用于当前轮换提案、允许任意原生承诺的游戏。

所有响应按完整后续效用决策：先自身，平局再其他玩家收益。B可以为了后续更好的合同拒绝当前非负合同；验证程序没有把首次回应简化为静态偏好正负号。

### 为什么调查有独立价值

调查X会得到want/neutral/avoid，恰好识别T1/T2/T3。剩下一次提案分别签X/Y/Z，A的预期收益：

`V_investigate_X = (1 + 2 + 2)/3 = 5/3`。

不调查时允许完整的自适应试探：根据第一笔offer的响应，最优选择下一合同。比如先Y，若拒绝再Z，服务T2/T3，预期收益4/3。先X、若拒绝再Z的一个策略也达到4/3：所构造的后续策略下T1/T2接受X，T3拒绝后签Z。

程序不仅比较这一条手选路径，还枚举了32个宽松策略顶点：首次所有非负合同可以任意接受/拒绝（允许比真正最优响应更宽的集合），然后任取下一合同；负收益的首次接受被排除，因为B可拒绝所有合同保证0。对混合回应和混合后续报价，收益是这些概率的双线性函数，其最大值可以在已枚举顶点取得。因此这个放松问题的4/3是包含混合策略在内的不调查上界。

另外枚举每种首次报价的B逐类型最优响应与拒绝后的Bayes belief，验证A最后报价的最优性及响应社会平局，构造一组完整策略和明确的离轨belief。该策略下root值为：

| A首步 | 最优后续下A预期终局收益 |
|---|---:|
| INVESTIGATE X | **5/3** |
| INVESTIGATE Y / Z | 4/3 |
| OFFER X / Y / Z | 4/3 |
| PASS | 2/3 |

调查首步优势为 `1/3`。没有额外调查奖励、没有拒绝惩罚；双方是在完整两机会博弈中决策，A不在调查前偷看B真实类型。

### 信息收益与行动优势分开

固定先做调查X、保持同一机会消耗，但屏蔽返回答案，A剩下的最后报价在三个类型下只能实现2/3。因此此原型中：

- 调查相对最优不调查策略的优势：`5/3 − 4/3 = 1/3`。
- 同一调查行动下，真实答案相对屏蔽答案的价值：`5/3 − 2/3 = 1`。

这两个量不是一个指标，不得混写成旧数据的S标签。

### 两个反向控制已验证

1. 将T2对X的neutral改成avoid，使三种类型均为“只want一个项目、avoid其他项目”。每个单槽查询只有二值结果。最好的单槽调查与不调查均为4/3，严格调查优势为0。
2. 保持原类型，但允许三次提案。直接按Y→Z→X试探，能按完整响应规范为每种类型签其最优合同；不调查也达到5/3。调查优势为0。

这支持“信息分辨率、资源占用和期限共同产生差异”，不支持“有相关性就必然需要调查”。原型不会因为给OFFER多一次机会还一直声称INVESTIGATE更好。

验证程序：[verify_contract_witness.py](../../new/game_mechanism_design_20261021/verify_contract_witness.py)。全部值用Fraction精确算术；[机器结果](../../new/game_mechanism_design_20261021/witness_results.json)保存策略、belief、上界、控制和范围声明。不是生产solver、当前数据集或唯一均衡证明。

## 5. 正式新游戏需要哪些检查

本原型证明了机制可行，但仍需决定是否保留原轮换提案，不能把“增加一轮”当作已经解决。若保留轮换提案，B/C可主动报价，会产生新信号和替代路径，调查优势必须重新完整求解。

建议先2人、3–4合同、每人最多3–4个联合类型；在受控的proposal期限下完整求到终局。若每人3种类型，两人只有9个隐藏world；行动菜单和资源约束明确后，可先控制公共树规模，再考虑三人。三人扩展需重新验证，不直接复制两人标签。

应把以下内容同时作为公开规则和求解器输入：合同可行性/资源预算、期限、联合类型及其先验、谁观察什么、调查成本与次数、真实终局收益、响应平局规范。

## 6. Solver和标签的改进顺序

1. **信息集正确。** 初态Chance抽完整隐藏类型并固定；玩家只知道自己的类型和收到的答案。不能逐个真实world当作完全信息游戏求解，再把答案当标签。调查后的信息分区应按公开依赖规律正确更新。
2. **整个游戏求到真终局。** 候选profile对所有玩家使用相同规范；标签针对已声明的完整profile，不在每个入口重选一个有利解。完整枚举树不等于已求出均衡。
3. **自身与其他玩家收益向量一起传播。** 先自身最优，仅response平局比较others sum，剩余动作允许多个正确标签。不要以固定加权和允许牺牲自身收益。当前v8 own-only评分缺口必须先修复，见[前一轮核对](PROMPT_PROTOCOL_REVIEW_20261021.md)。
4. **独立验算。** 全部信息集检查策略不泄漏隐藏信息、完整best-response deviation、响应平局、终局payoff和Bayes reach；数值不收敛/预算耗尽记为无标签，不能写S=0。
5. **复用不改变定义。** 可按资源/合同/剩余期限/私有观察历史缓存同一reference下的树和续值；只有在收益、未来合法行动、信息集与perfect recall都相同时才可合并节点，不能只看当前binding相同就合并。

两人一般和扩展式博弈已有[sequence-form路线](https://doi.org/10.1111/1468-0262.00300)，可作为规模增大后的候选；不需要先以MCTS替代精确标签。不能将两人零和CFR的Nash保证直接搬到当前一般和/三人游戏；[OpenSpiel的CFR实现](https://github.com/google-deepmind/open_spiel/blob/master/open_spiel/python/algorithms/cfr.py)也明确给出两人零和的适用保证。本提案没有替换生产求解算法。

## 7. 信息筛选不能只看D或答案熵

新机制建议至少分开报告：

- 最佳完整策略允许/禁止调查时的收益差（含所有未来offer试探，不能与固定、近视报价比较）。
- 首步最佳调查对最佳非调查行动的Q gap。
- 相同行动/成本/物理状态/对手策略下，保留和屏蔽真实答案的最优策略价值差。
- 获得不同答案后，最优后续动作集合是否确实变化，且是否有可分辨的regret gap。
- 初始认证profile下这些节点的实际reach，不把人为外加PASS前缀当自然可达。
- 自身utility信息价值与仅改变response次级正确动作的影响分别列出。

Blackwell关于[信息实验比较](https://digicoll.lib.berkeley.edu/record/112749)提供了区分信息充分性与决策价值的经典出发点；这里OFFER还改变物理状态、消耗期限并受到策略响应影响，不能只比较信息bit数就推断整个博弈中调查一定更好。

除了严格需要调查的机制，还必须有直接报价更优、不必调查及答案不影响行动的控制，避免学到“总是调查”。联合偏好规则固定，但每局仍抽真实类型，且按真实结构family划分数据，不能只改玩家/项目名字制造新题。

## 8. 建议的当前决策

优先确定“有限完整合同 + 稀缺资源 + 有限期限 + 公开联合类型”的游戏草案；先用上面的可手算机制作为solver回归基准，再验证保留轮换提案的版本和三人版本。保留OFFER的试探价值，不通过强迫先调查或额外奖励来制造差异。

本轮只完成设计、精确验证和留痕。没有生成新训练题库、重跑D、修改prompt、替换既有Oracle或启动训练。
