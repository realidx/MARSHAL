# 私人答案组当前损失下界诊断

v1汇总实现未运行；本版本增加一个数学诊断，不改变节点Q/S或选择标准。
给定同一public node/own type/其余答案，遗漏答案后必须共用当前行动分布。令w为旧counterfactual入口权重，
Q为各完整入口在当前动作后恢复完整信息最优续接的表：

`LB = sum_i w_i max_a Q_i(a) - max_a sum_i w_i Q_i(a)`。

它是在当前行动后恢复全部信息的放松问题损失，故`0 <= LB <= 实际遗漏当前损失 <= 实际完整S平均`。
与canonical平局混合无关，但仍依赖固定reference和w；不是跨均衡稳健性。
只对私人答案分组，严格核对旧full_contexts；不按物理骨架合并历史。LB为0不排除后续S或模型困难。
正值使用既有1e-8数值分辨率，未定义训练准入门槛。
