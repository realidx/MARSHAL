## Q/S的数学解释：已有基础，不提前冻结筛选公式

令q(a)=Q_I(a)，q-(a)=Q_{I-e}(a)，两者有同一合法菜单。
q-是遗漏信息后信念与后续策略约束下的主观行动估值，不能直接当实际场景的收益损失。

### 相对行动价值是线性决策问题的完整描述之一

对任意行动分布p，当前固定p、随后按相应条件最优规划的收益为p·q。
在所有行动Q加同一常数c时，任意两分布p、r的偏好差不变：

```
(p-r)·(q+c1) = (p-r)·q
```

所以用`max(q)-q(a)`或所有`q(a)-q(b)`描述相对行动价值，有加性平移不变性。
`d=q--q`在信息遗漏前后如何改变两个分布的相对估值，有精确表达：

```
[p·q- - r·q-] - [p·q - r·q] = (p-r)·d
sup_(p,r属于概率单纯形) |(p-r)·d| = max(d)-min(d)
```

上界由p集中在d最大动作、r集中在d最小动作达到。这给出整张相对Q表变化的数学含义：
遗漏信息改变了多少潜在行动偏好。它不是LLM实际损失，也不是已批准的最坏情况筛选分数。

### 行动分布变化通过效用加权连接到当前S

令p+为完整信息最优当前分布，p-为遗漏策略当前分布，在真实完整信息Q下评价：

```
S_current = (p+ - p-)·q
          = sum_a p-(a) [max(q)-q(a)]
0 <= S_current <= [max(q)-min(q)] TV(p+,p-)
```

因为p+仅支持完整信息自身最优动作。这个上界说明分布距离和决策收益有关，但不能互相替代：
在两个等效动作间完全切换，可以TV=1而收益损失为0。
response的社会次级规则需另列，不把他人效用损失混入own S。

令q-e-true(a)为遗漏最优后续策略在真实完整入口的行动Q，则旧完整策略S满足：

```
S_total = S_current + sum_a p-(a)[q(a)-q-e-true(a)]
```

因此当前动作分布不变仍可能有后续S。完整/遗漏信念不同，也意味着不能直接用两张主观表的max差当实际S。
若将p+、p-换成真实模型的两种采样分布，该效用加权差可有负值，不继承最优Oracle的非负性。
完整trajectory的模型D也不等于只评价当前一步的该差值。

### 行动分布需要行为约定

未正则化Q只约束最优动作支持，不唯一规定剩余平局概率。
现有profile的uniform canonical Oracle、TV/JS是明示约定下的诊断；不宣称是目标模型分布或平局无关的重要性。
不未经讨论引入softmax温度、权重和正S准入门槛。
