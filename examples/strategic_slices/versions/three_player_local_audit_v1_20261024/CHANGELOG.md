# 逐项执行变化

父研究的游戏、solver、Q/S实现与默认值不变。
本地main33、缺失2局较大预算retry、独立reload、LP验证与query35诊断分开记录，均不覆盖原输出。

| 项目 | 父版本交付时 | 本次执行 |
|---|---|---|
| H2完整33局 | 未整批运行 | 本地全部尝试 |
| 候选求解预算 | 默认600秒 | 首次120秒；仅缺失局重试600秒 |
| 原生认证预算 | 默认300秒 | 首次/重试180秒 |
| Q/S预算 | 默认1200秒 | 首次/重试300秒 |
| 整局硬限 | 默认3600秒 | 首次720秒；重试1200秒 |
| 内存限制 | 默认8GiB，仅Linux有效 | 本地macOS显式0，无地址空间限制 |
| 并发 | 默认1 | main/retry1；保存后reload2 |
| reference来源 | 小样及一例声明复用 | main33均重新搜索；保留首次认证profile |
| 题目筛选 | 已冻结H2/H3/A2H2 | 只执行H2；不按成败或信号换题 |
| 新诊断 | 原预定小样LP | 本批新见证LP与35的答案屏蔽/入口posterior |
| prompt/训练/D | 未执行 | 未执行 |

动机：按用户要求确认本地可行性、区分树规模与候选收敛问题，验证信号是否来自当前信息的实际利用。
实际运行与关闭状态由SNAPSHOT.json中的结果和hash确定；CPU证据不代替GPU或训练效果。
