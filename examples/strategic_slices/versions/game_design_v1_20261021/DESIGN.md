## 1. 游戏环境与原始100题

| 项目 | 当前设计 / 本批配置 |
|---|---|
| 实验目的 | 比较game slices与完整self-play的训练效率，不设计新GRPO方法 |
| 人数、轮数、目标 | 67个两人局、33个三人局；全部2 RR；每局3或4个目标 |
| 可承诺事项 | 两人局每人2项，三人局每人1项；每目标要求2或3项、涉及至少两人；同一事项可被多个目标使用 |
| 终局收益 | want / neutral / avoid分别为+1 / 0 / −1，乘目标完成度后求和；binary要求全部满足，linear按满足比例；目标计分模式各以1/2概率抽取 |
| 偏好生成 | 公开、独立的want/neutral/avoid各1/3先验；公开值抽取后固定，隐藏值按先验实现；dependent preference暂缓 |
| 隐藏规模 | 全局隐藏单元：两人局2或3个（9/27个world），三人局1个（3个world）；这是本批计算规模限制 |
| OFFER | 仅自己与另一玩家；每方最多新增1项承诺，可一方为空、不可双方都为空；接受后承诺不可撤销 |
| 报价代价 | 每人每局1次；提出时立即扣额度，接受或拒绝均不返还；不直接扣utility |
| INVESTIGATE | 每人每局1次，仍消耗当前proposal回合；只能查其他玩家未公开、且自己未直接查过的偏好；不因可推断或无用而删目标 |
| 回合与response | 每RR每人一次proposal机会；PASS、调查、OFFER占用该机会；ACCEPT/REJECT不占回应者后续proposal机会；无少回合/少调查奖励 |
| 信息披露 | 所有公开偏好、自己的全部偏好、完整公开行动历史、累计自己的调查答案及当前状态；他人的私有调查答案不可见；答案不额外标来源 |
| 平局规则 | 全体先最大化自身预期终局收益；仅ACCEPT/REJECT自身收益平局时最大化其他玩家收益之和；不扩展到proposal |
| 原始池准入 | 100题在solver与Q/S/D前冻结；只做结构覆盖与重命名去重，不按偏好质量或求解成功筛题；失败不换题；尚未划分split |

完整分层数量、随机种子、生成配置和数据hash见[原始池记录](../../PARENT_POOL_V1_20261021.md)；
游戏规则实现版本为`native-private-unknown-query-offer-quota-v1`。
人数、目标数、轮数与额度是可变设计维度；上述数字仅为本批配置。

## 2. Solver如何计算

枚举完整公共行动树与隐藏偏好world，在玩家各自的信息集上搜索一般和策略profile：
先尝试纯策略best response，再按需搜索混合行为策略。所有玩家使用同一种求解方法。
当前2 RR游戏要求所有叶均为原生terminal；内部lookahead RR=3，不使用非终局近似叶值。

候选profile必须通过完整合法行动的单边偏离检查、局部自身最优支持及response平局检查。
自身偏离容差`1e-8`、平局容差`1e-9`；不以搜索时保留的少量候选行动代替完整认证。
零可达信息集采用与自身偏好/调查答案一致的条件先验约定。
这是数值认证，不保证收敛、唯一均衡或形式上的sequential equilibrium。

| 远端搜索预算 | base | extended |
|---|---:|---:|
| 每次求解 / 审核时间 | 300 / 180秒 | 900 / 300秒 |
| sweeps / candidates | 256 / 8 | 512 / 12 |
| joint cells / evaluations | 65536 / 640 | 131072 / 2048 |
| large-tree ordered sweeps | 4 | 8 |
| 初始化顺序 | uniform | uniform，Dirichlet seed 0、1、2 |

共用：构树120秒、最多100000公共历史、每worker数值库1线程。
按声明顺序取第一个通过认证的profile；超时或不通过者无标签，不能记作零信号。
复用须核验数据、source与数值环境身份，保留原profile来源；不根据Q/S/D挑profile。
完整参数、依赖、恢复规则与操作见[远端指南](../../REMOTE_SOLVER_20261021.md)及[机器快照](SNAPSHOT.json)。

## 3. Q / S / D的计算约定

| 量 | 已确定的含义 | 仍需确定 / 实现 |
|---|---|---|
| Q | 当前玩家、当前信息下，行动及后续策略至原生terminal的预期收益 | 节点Q展示统计、其他玩家延续profile和反事实策略约定；不能擅自把max−min当最终重要性 |
| S | 当前节点逐条遗漏已有信息后，所选策略在真实完整信息下造成的终局收益损失 | 信息遗漏单位、合并信息集后的策略约束、并列策略和response次级目标；新S尚未实现 |
| D | 用实际目标模型在最终题面/接口上的表现测量；Q/S必须结合模型D判断节点价值 | 最终公式、模型身份、采样次数/参数、失败处理；新D未测 |

S的比较方向为`S_e(I) = V_I(pi*_I) − V_I(pi*_{−e})`，两策略都按真实完整信息I评价到terminal。
只允许遗漏**自己的调查答案或公共历史提供的信息**；保留公开偏好、规则、目标、自己的偏好、
当前承诺和待回应报价等真实状态。先逐条遗漏；不替换成误解或事前调查价值。
保留证据仍能推出同一事实时，额外贡献可以为0；遗漏策略不能从节点编号或posterior偷读答案。
该式目前是设计语义，尚不是完整可执行规范。

旧有限窗口Q/S、旧prompt测得的D不改名为本版结果。
Q大不等于模型会错，Q小也不等于无训练价值；Q/S/D联合选题规则、阈值、split与SP匹配预算尚待确定。
