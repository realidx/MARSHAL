# 调查235入口：答案价值与前后标签链条

2026-11-04。已完成51个父游戏、235个调查严格最优入口的全部353个合法调查分支。
结果说明不能把“调查Q最高”直接等同于“必须利用调查答案”。

| 入口结论 | 两人 | 三人 | 合计 |
|---|---:|---:|---:|
| A：答案对调查严格胜过非调查必需 | 93 | 16 | **109** |
| B：答案增加收益，但无答案调查仍严格更优 | 37 | 2 | **39** |
| C：无该次答案仍能达到原最优入口收益 | 63 | 24 | **87** |
| 未完成/核验失败 | 0 | 0 | 0 |

109个A入口来自25父游戏，其中104个保证至少两次本人决策；三人16个A入口来自5父游戏，11个保证至少两次本人决策。
39个B入口来自16父游戏，全部保证至少两次本人决策。A+B合计148入口、33父、70个物理骨架；
物理骨架只检查结构集中度，不是历史/信念等价类，不能直接当成70个独立信息题。

## 具体比较的是什么

固定相同入口的原生公开历史、既有自身信息和counterfactual belief，逐一强制每个合法调查动作：

- **full**：获得答案，当前玩家后续按完整信息最优规划到原生终局。
- **blind**：相同调查仍公开发生，同样扣额度/消耗回合，但该目标答案在后续所有本人决策中不可访问。
  既有自身信息、公开历史与以后公开行为提供的推断保留；对手始终使用同一保存reference。

对每个入口，令`F=max_query full`、`B=max_query blind`、`N=max_nonquery 原Q`；本批入口均满足`F>N`。
分类沿用1e-8数值分辨率：A为`F>B且B<=N`，B为`F>B>N`，C为`F=B`。
**比较所有调查目标后才给入口结论**，没有任意挑一个最优目标代替其他可选目标。

N保留原非调查行动的完整后续策略，可能包含稍后正常调查；这不是终身禁止调查答案的对照。
C表示在该入口可不依赖当前这次答案获得同样收益，不表示调查无效、所有信息无用或该场景无战略价值。
blind仍可能通过公开行为和之后对手反应产生收益；本次没有隐形调查或重求均衡，不能把剩余收益全部归因为纯公开信号。
这是固定reference下的答案访问诊断，不是新定义的当前节点S或跨均衡证明。

## 与已有S是否一致

另做独立的原生前向重放：调查后只运行对手reference，直到第一次本人决策或终局。
每个到达的本人完整信息context，核对条件belief与保存profile一致，读取该次调查目标的既有私人答案S。

全部353条调查分支均满足：

```
full_query - blind_query
  = sum_c P(第一次本人决策的信息context为c | 当前入口、强制该调查) * S_private(c)
```

调查后到终局都没有本人决定的分支，两种答案访问条件下收益相同、差值抵消。
首次本人决定之前，公开历史可能已经推断出答案；这种情况保留推断能力，不能强行制造信息损失。

共3522次后继完整信息context出现（含重复出现，不称3522个独立题目）全部belief核对通过。
full、blind及上述差值分别核对，最大误差约1.34e-15、1.56e-15、6.25e-16。
这把“调查前的答案增益”与“调查后已有信息S”连接起来；两者不是任意定义的两套不相容评分。
未把该恒等关系推广为公共历史所有遗漏通道的公式，也未替换主S。

## 验证范围

353个full收益全部匹配保存的相应调查动作Q，最大误差2.23e-16以下。
每个full/blind问题都做独立sequence LP：整批706次LP与DP全部匹配，最大误差8.89e-16以下。
LP优化own收益、放松社会次级约束；DP仍沿用原回应规则，实际own最优收益一致。
使用已经核验的严格零对手CF分支裁剪，保留全部可达本人动作；最大实际保留forest6971节点，无近似截断叶。
非调查N继承已核对身份的完整profile，本次没有重新逐动作求其LP，也未新搜索reference均衡。

四父pilot19入口/22调查分支与整批对应结果一致；所有CPU运行workers2、数值线程1，实际source/CLI/参数/hash独立保存。
706为整批LP次数，不混入pilot额外44次LP。没有模型调用、训练或D测量。

## 对800入口的直接意义

- A类109入口可作为“获取信息再利用”的核心候选；不能按节点数随意重复扩充。
- B类39入口保留为混合动机场景，和A类分别统计，避免把答案增益与调查必要性混称。
- C类87入口移出“必须利用当前调查答案”的覆盖计数，可作为公开行为/规划等场景继续审查，不直接删题。
- 三人严格信息获取A类目前只覆盖5父游戏，不能靠16入口宣称广泛结构覆盖。
  这只限本次query_gap>0子集，不代表三人已有信息利用、调查平局入口或整个游戏仅这5父有信息价值。
- 现在可据此确定800的信息获取/已有信息利用/估值规划/回应配额及重复控制。
  若希望更广的三人信息获取覆盖，应针对结构缺口补父游戏，保留现有合格信息利用来源身份。

本轮没有选800或分配train/validation成员，也没有改变600/200拟采用规模、父65/35比例或激活训练。
