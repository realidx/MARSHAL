# CalBench v12-inbox scaffold evaluation on H100-47

## What changed

v12 fixes one projection bug: messages already delivered in the native first-turn inbox were moved into ACTION and were missing from MS and later MS history. The complete inbox is now retained in the MS observation and later projected history; only action directives move to ACTION. MS/ACTION wording, native game and parser, frozen 24 cases, temperature, accepted shared 4096-token budget, retry policy, and scoring match v11. See the [registered example](../strategic_slices/versions/general_ms_calbench_v12_inbox_20261102/EXAMPLE.md), [all actual requests](../strategic_slices/versions/general_ms_calbench_v12_inbox_20261102/preview/PROMPT_PREVIEW.md), [snapshot](../strategic_slices/versions/general_ms_calbench_v12_inbox_20261102/SNAPSHOT.json), and [offline evidence](../strategic_slices/versions/general_ms_calbench_v12_inbox_20261102/EVIDENCE.json). The 94 offline checks and fixture replays are not model-effect evidence. The snapshot remains marked `AWAITING_USER_REVIEW`; the user explicitly authorized these runs.

## Did the inbox fix reach the model?

I checked the first actual MS request for every agent in the saved runs. In the v11 raw runs, `New messages received:` was absent from 0/95 Qwen and 0/96 outcome-99 first MS requests. In v12, it appears in 49/96 Qwen and 51/96 outcome-99 requests that actually had an incoming first-turn inbox. For all 49 and 51 such requests, the received DM text was still present in every later MS request for that agent. This verifies the intended data-flow fix in the real model calls; it does not prove the models used each message correctly in their strategy.

## Comparison and interpretation

On the cases completed in both versions, v12 is descriptively better than v11:

| Checkpoint | Paired completed cases | Final-valid meetings | Full-stream games | Semantic-invalid actions |
|---|---:|---:|---:|---:|
| Qwen v11 → v12 | 23 | 23/69 → 25/69 | 1/23 → 3/23 | 65 → 40 |
| outcome-99 v11 → v12 | 20 | 23/60 → 28/60 | 1/20 → 4/20 | 40 → 36 |

The paired comparison uses the same case IDs, seeds, model checkpoints, and runtime profile; only the v12 inbox projection differs. It is a small benchmark, and two outcome-99 cases remain unresolved. Against the separate native-prompt baseline, the v12 totals remain lower (Qwen 25/72 meetings and 3/24 full-stream; outcome-99 30/66 and 4/22 versus native 38/72 and 8/24). The native comparison is descriptive because the scaffold condition changes the prompting protocol.

The direct engineering goal succeeded: first-turn inbox content is now present to the belief stage and remains in its later history. The matched outcomes move in a positive direction versus v11, but this run does not establish a broad performance gain; outcome-99 still has two different failure cases.
