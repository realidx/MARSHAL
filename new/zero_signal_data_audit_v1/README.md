## 具体瓶颈

### B2：要比较未选择的提案

linear 例 `7cd2fc6f9dba54d841b2` 只有一次自愿提案。Alex 已知想要 Orchard，Harbor 偏好未知；两个目标分别需要 Alex 的不同承诺和 Blair 的同一个承诺。观察到 Alex 选择完成更多 Harbor 的提案。比较其效用：

| Alex 对 Harbor 的偏好 | 已观察提案 | 另一个提案 |
|---|---:|---:|
| want | 1.5 | 1.5 |
| neutral | 0.5 | 1.0 |
| avoid | -0.5 | 0.5 |

指定 teacher 下观察动作的似然分别是 0.5、0、0，因此可缩集至 want。答案可推导，但“这个动作有好处”不足以解题，必须比较反事实动作。该类别仅一个几何、两个原始题，194 步调度中每个背景版本只出现 1–3 组。

### B1：部分收益与响应平局规则

linear `partial_harmful` 题中，接受使回应者获得 +0.5、0、-0.5，拒绝为 0。中性情况下，接受损害提案者，teacher 的利他平局规则选择拒绝。因此接受可排除 neutral；拒绝保留 neutral/avoid。binary 对照没有完成整个目标，可以全部为零收益，标签自然不同，不能按同一语义机械转换。

### P4：缺少空自身承诺的前置练习，且收益差较小

正确提案允许 `self_commitments: []`，工具 schema 和评分均支持。四种先验下，最优动作比 PASS／调查的收益优势分别约为 0.1667、0.125、0.25、0.125；评分容差为 0.1。两个 0.125 差距的情形距离接受阈值仅 0.025，并非很容易区分的强信号。

旧 P 数据只有 8 题的所有可接受动作都必须使用空自身承诺 OFFER：4 道结果利用和 4 道 ordinary_alternative，**没有 P1 基础题**。这是可直接补的递进缺口。尚无实际错误轨迹证明模型具体误选了哪种动作。

## 已生成的 16 道候选基础题

`bridge_candidates.jsonl` 与对应请求、检查和哈希清单已导出：

- 4 道空自身承诺题：只缺伙伴承诺；额外自身承诺反而有害。各含 binary/linear。
- 6 道 linear 回应题：自身偏好 want/neutral/avoid，结合两种对提案者收益方向，练习部分收益与平局规则。
- 6 道提案比较题：三种已知偏好，各含 binary/linear，为 B2 逆向推断提供正向计算前置练习。

这些题的偏好确实公开、世界唯一、原生轮次合法，工具和判分检查通过，并检查不复用旧验证／测试及 A 正式测试的几何。它们是 P1 基础练习，不向 B 泄漏隐藏答案，也不证明 B→P 已经组合成功。

**尚未并入正式训练数据，`training_ready=false`，没有模型调用或新训练。** 当前默认 v3 不变。下一步应将递进题与原有难题组成有配额的训练层级，而不是只复制更多难题；是否形成有效梯度需在后续正式训练中监测。

本次未修改 SP。长局不完整导致的组内终局信号缺失仍需单独处理，不能用这份 B/P 审查解释。

## 复现

在仓库根目录，使用已有 Python 环境：

```bash
python -m training.social_mixed.audit_zero_signal
python -m training.social_mixed.audit_zero_signal_forward
python -m training.social_mixed.build_zero_signal_bridges
```

详细证据：`summary.json`、`tasks.json`、`policy_sensitivity.json`、`mode_pairs.json`、`p4_forward_replay.json`、`bridge_checks.json`。零组内 utility 差异意味着缺少该组的区分性任务梯度；共享参数和其他损失仍可能改变模型，不能称为完全没有参数更新。
