# 旧 B/P 覆盖与效果核查

运行：`PYTHONPATH=. python new/old_bp_exposure_audit_20260923/audit.py`。未调用模型，未修改训练配置。

## 证据范围

本地有两个旧 segment 的 metrics、21 个固定静态验证点（0–200，每10次）、15 个训练 calls 窗口；不是完整逐步训练输出。重建 sampler 在15个窗口的题目ID集合全部吻合，前100次每步回答数也全部吻合。曝光统计是据此支持的确定性重建，不是假称全程calls实测。不同阶段的实际恢复状态仍须与运行记录一起解释。

## 覆盖结果

前50步441题组，覆盖338/594题；四类重点练习全部覆盖。前100步927题组，覆盖530/594题，仍有64题未出现。此时bridge的16题各出现3–10次，history的27题各2–4次，reduced的54题各2–4次，result的38题各3–4次。角色集合可能重叠，不能相加为独立题总数。200步重建覆盖594/594。

这说明配额保障了重点练习覆盖，并非全库均匀重复，也不是固定少数题密集训练。没有去掉配额的模型训练对照，不能证明配额带来的能力增益。

## 建议而非已实施

保留当前Q0起点、B无正确previous-belief辅助、P无历史定性接口、奖励与归一化。优先改变采样单位：合法反馈窗口与实际reward接受集合不相交的must-change对作为完整关系组；每题仍独立八采样和归一化。当前已有关系采样，应改进累计覆盖/轮换，不宣称新引入配对。

按结构和关系组记录累计曝光、最近访问步数、有效对比次数；先保障长期未访问成员，避免共享控制题占满预算。增加关系级验证（两端同时正确、更新/保持区分），避免只观察单题均分。不把验证题放进训练。

更小批次/更多更新是独立优化变量；第一版不与覆盖修改同时变化，以免混淆因果。以上只能检验训练结构是否学会和保持，不能保证保住训练分布外Q0的CalBench行为。未修改或启动训练。
