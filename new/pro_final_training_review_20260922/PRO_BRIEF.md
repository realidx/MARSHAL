## 2.1 新旧题目具体长什么样：不是同一批题换了训练臂名称

以下对照来自实际 `data_reasoning_v5_candidate/bp_train.jsonl` 与 `paired_bank_v2/tasks.jsonl`，不是根据B/P名称推断。两者使用相同类型的原生合作博弈：玩家有want/neutral/avoid偏好，目标要求若干人的行动组合，模型通过工具提交提议、接受/拒绝、跳过或调查。题目同时包含binary（组合完成）和linear（部分完成有价值）结构。**底层游戏相近，但输入接口、任务组成、训练/验证划分和评分条件均有变化。**

| 比较项 | 旧 B/P-99 的题目 | 本轮 paired_bank_v2 的题目 |
|---|---|---|
| B 的任务 | 形成判断、根据新证据更新、在不支持改变时保持判断 | 每个canonical局面生成一条单项belief形成/推断题；训练B行均标为B1/formation |
| B 输入 | formation给可见局面/历史；update、maintain题还包含previous_belief、old_history、new_history | 从当前可见局面/历史推断指定伙伴对指定目标的偏好，不保留旧update/maintain的显式练习接口 |
| B 输出 | possible_preferences和favored，工具输出定性判断 | 仍是possible_preferences和favored；没有改成数值posterior输出 |
| 旧P/当前O | 旧P中已经包含根据历史直接行动的题，另有给定belief的规划题 | 统一分出O：不给辅助belief，由历史/可见状态直接选行动 |
| 当前P | 旧P接口混合：完整已知偏好、精确联合概率、定性不确定性、历史规划、是否调查及调查结果利用 | P（文件名Pplus）：去掉历史，提供定性belief及必要当前状态、自身偏好，选行动；不用概率数字 |
| 题目之间关系 | 有独立B/P，也已经有同历史B/raw-P/oracle-P练习组，不能说旧库完全不关联 | 系统化为每个canonical局面的O/B/P三视图；不是把模型生成的B答案实时传给P |
| 标签与训练资格 | 依各旧任务的teacher与可接受动作评分；已有部分定性认证 | P按定性belief兼容范围认证对/错，含masked回答、evaluation-only和quarantine；不是所有P行都参与语义训练 |

### B：最大的变化是显式更新/保持练习被统一成了单次推断

旧训练294条B：formation 77、update 134、maintain 83。按kernel分则B1=113、B2=52、B3=129；**kernel和skill是两个不同维度，不能把B1/B2/B3分别机械等同于formation/update/maintain**。

本轮训练文件373条B全部标记B1/formation。它们仍可能有复杂历史，来源也可能是旧B2/B3结构；但“给旧belief＋新增证据，明确要求更新或保持”的监督形式不再原样保留。训练D才会实际训练这些B；本轮O和C没有直接B训练。

通俗示意（解释接口，不冒充逐字原题）：旧update题会问“此前认为伙伴可能want/neutral；现在看到新的拒绝行为，应该如何更新？”maintain题则检验“新事件没有额外信息时是否保持原判断”。当前B主要问“看完这段可见历史，伙伴对目标可能是什么偏好、目前更支持哪个？”两者都能包含历史推理，但训练模型执行的操作并不完全一样。

### 行动题：旧P本来就不只等于现在的P

旧训练300条P，P1/P2/P3/P4分别88/90/24/98。实际例子包括：

- P1 `000c6314b41be421b96d`：已知自己avoid目标0、want目标1，当前提议会完成自己不想要的目标；从ACCEPT/REJECT中选，标签REJECT。这是偏好已知下的行动选择。
- P2 `0169fb4f77e8bb183237`：输入直接给两个未揭露偏好的精确联合分布（例如43/225、1/90等权重），要求据此规划；另有history_planning子类，不能说所有P2都直接给数值belief。
- P3 `072ccfe6bb43d8030c07`：定性不确定条件下的行动，teacher含qualitative_certificate；所以定性规划不是本轮首次引入。
- P4：既有是否值得消耗提案机会去INVESTIGATE的题，也有看到调查结果后如何行动的result_use题。旧P4共98条，其中information 40、result_use 58。

当前同一局面分成三种请求：O给历史让模型自己推断后行动；B给历史只问偏好；P不再给历史，直接告诉模型类似“want、neutral都可能，更支持want”，再让其行动。**“旧B/P”与“当前D的B/P部分”不是同一个训练任务分布；当前O也承接了旧P中的一部分功能。**

当前训练373个canonical局面的O与P视图，其行上的kernel构成为P1=115、P2=143、P3=4、P4=111。这是当前行标签计数，不是373个独立游戏，也不是实际P有效更新分布；P还受训练资格/屏蔽影响，实际曝光应查calls。不能将它与旧300条P的计数直接当作等量任务配比。

### 训练题与验证题也换了，不能直接横比准确率

- 旧v5：训练594条B/P，开发题库495条；周期静态验证固定45题（20 B、25 P），另加8局完整交互。
- 当前配对库：497个canonical局面按parent分成373 train、124 validation，再各生成O/B/P视图；这是局面数，不能与旧594条单任务数直接比较。当前固定静态面板73题（25 O、25 B、23 P），早期/中间O监测复用其中25道O，不是又一套完整交互验证。
- 所以旧99的B/P正确率与当前O/B/P准确率不属于同一测试；旧与当前的完整交互8局也不能仅凭相同局数认定题目、基线和执行条件一致。应以各自run的实际请求和reset标识核对。
- 当前同一训练链的固定O面板可以比较趋势，但存在已说明的推理噪声；跨旧/新面板不能把分数差直接称为学习退化。共同冻结CalBench提供另一个对照，但也须保留headline、成功、最优和逐局变化，不能以单一指标替代。

**需要PRO正面判断的含义**：新设计提高了三视图关联性和P接口一致性，但也改变了旧训练的显式belief更新/保持、精确不确定性规划和信息获取练习分布。它可能强化了某些局部判断，却没保留同样的训练操作组合。这是有具体数据支持的候选解释，不是已经证明旧99优势来自某一种题；也不能据此直接要求恢复数值belief或恢复整个旧库。

## 4. 本轮实现与实际执行

关联库497 canonical cases/175 parents，按 parent 分组拆分373 train、124 validation。O：历史→动作；B：历史→定性 belief；P：无历史、给定性 belief→动作。不同视图来自同一决策结构。当前 B 查询主要是单项推断，不等于旧 B 全部任务类型。

C 为 O:P=2:1；D 为 O:B:P=1:1:1。固定槽位使 C/D 的 P 对齐；C 中一部分 O 在 D 替换为 B。D 不是纯“在 C 上额外加 B”，O 曝光也变了。SP 是完整交互、自身策略控制所有席位，不是固定伙伴。

P 的屏蔽：对定性 belief 无法认证为明确对/错的回答，不伪造负奖励；语义奖励可屏蔽，协议与 KL 项仍有各自处理。训练库 P 为314 eligible、29 evaluation-only、30 quarantine；验证106/4/14。不能把屏蔽后的样本数当作原始采样数。

P 世界范围审计497/497覆盖可见条件允许的世界；49个零后验世界也保留。174个直接终局案例独立复算收益（139 train/35 val）。多步 continuation 表仍可能依赖 P 看不到的历史；175个 eligible train 多步案例的限制仍在。309个相同 P prompt 对未见标签/价值冲突，不等于一般性充分性证明。用户已明确：此项不是必须阻止训练的硬门禁。详见 P_WORLD_SCOPE_AUDIT.md、P_CONTINUATION_AUDIT.md。

## 7. control 与行动相关题：最值得 PRO 正面分析的证据

relevant标签：在选定伙伴/目标的不同偏好下，固定continuation表，精确最优动作集合发生变化；通常不要求集合不相交。另有匹配的belief翻转/稳健动作不相交规则。control仅指未满足该检测，**不代表不需要社会推理、没有历史、简单题**。

固定验证的10道relevant仅来自2个parent：P2/binary四题、P4/binary六题。P2不同偏好下有大量共同最优动作，并不必须换动作。P4四题全程观测都错，一题仅step4对，一题多次对。这更像一个结构未稳定学会，而不全是先学会后遗忘。

| 臂 | Q0 relevant/control | 终点 relevant/control |

## 8. 优化日志能说明与不能说明什么
