# B/P 首轮训练准备完成记录

2026-09-14。本地实现与审查完成，**没有启动远程训练**。运行说明和冻结文件在 `examples/social_bp/README.md`。

## 已解决的具体问题

1. **旧 reward 会奖励错误 fallback 的相对表现。** 新 B/P 路径采用正确 1，错误/格式失败/截断 0；保留旧 probe 的评分以便回放。实际旧结果的 43 条失败回答已重放，全部为 0。真实 ROLL group normalization 检查确认全错组的任务优势为零，错误全集不再因同组有人截断而获得正任务优势。没有引入长度奖励或文本 JSON 修复。
2. **训练接口与新题面脱节。** 原生 B 提交、P 的 OFFER/INVESTIGATE/PASS/响应工具统一接入导出、Hermes parser 和 reward worker。教师数据仅放 ground_truth；prompt/tools 由可见投影生成。导出会拒绝哈希或 tokenizer 模板不匹配。保留引擎原始 token 和 finish reason，不根据文本猜是否截断。
3. **配额和实际曝光不一致。** B/P 每轮各 8；B 的 formation/maintain/update 为 3/2/3，P 四池各 2。每 10 步精确兑现难度比例；每轮调查正负各 1，直接读取最多 1 道 B。保持探索，不按模型失败过滤困难题。模拟 100 步时，B 直接读取实际占 5.5%–6.375%，全集标签约 19.25%–24.625%；不同进阶情景下均有 favored-only 更新曝光。
4. **有候选题但关键能力漏选。** 加入硬性覆盖：集合不变而 favored 更新、多元素 favored、调查自身收益正例、仍有后续机会的不调查反例。三个 split 都具备这些类别；不再仅靠随机抽样。调查负例包括多次承诺建设需要占用提案机会的原生残局。
5. **旧 probe 混入 held-out 的风险。** 根据全部已有 no-catalogue、named-bridge、readable、SoC probe 整理五个开发家族，只允许进入 train。其余按玩家/goal/commitment 重命名不变的结构 family 划分，语义重复和相邻 checkpoint 不跨 split。
6. **旧 belief 和调查结果时序可能含糊。** 直接真值更新题安排在调查结果刚送达、没有插入其他事件的合法 checkpoint；P 的结果使用题单独呈现后续合法历史。120 道带旧 belief 的题重新核对。
7. **验证太晚、总体分数掩盖退化。** step 0 和每 10 次更新验证；每步另存训练 group 状态。分开记录缩集/保留全集、误缩集、favored-only、调查正反例、likely 和截断。B/P 分别进阶；关键对照退步阻止升级。最佳模型按各能力池宏平均，并对关键对照回退加保护。
8. **step 数和真实更新数可能不同。** 有效 batch 128、PPO epoch 1，4 张训练卡×microbatch 1×accumulation 32。配置解析验证每卡 100 次更新；运行时读取 DeepSpeed 实际 global_steps 增量并要求每轮为 1。
9. **SoC 启动路径不完整。** 独立环境、原生 parser 导出检查、6 卡 Slurm launcher、训练前配置审查、checkpoint 保留策略和最终 64×8 held-out test 脚本均已准备。基础设施异常直接终止，不混入优化数据；本版没有自动基础设施 retry。

## 仍需实验回答，不能声称已解决

- 模型是否能在这些桥梁上采到正确回答、是否逐步摆脱全集/调查默认倾向，需要首轮 GRPO 结果。数据和奖励修复不是学习成功证明。
- 难度标签是初始结构近似；优先在 30 步看分层趋势，不保证 100 步收敛。
- Teacher 标签针对固定流程选中的、经检查的策略；循环或超预算候选不贴标签，也不被宣称无解。完整 self-play 分布不使用这份可解教学库替代。
- 部分最短自身信息价值正例依靠合法 round 边界次序。它证明私有答案可以改善后续自身计划，不证明任意轮转和任意对局都如此。
- 定性词语采用宽解释域且仅训练全域有稳健行动集合的题；该解释域仍是操作化约定。四人长局、所有 favored 反转方向、更复杂联合 belief 后续继续扩展。

不再为让 base model 的每条 reasoning 看起来正确而增加 prompt 干预、retry 或 length penalty。当前完成的是首轮可检验的训练准备。
