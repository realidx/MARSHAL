## 范围与证据

读取新归档的旧BP99 strengthened-v6两次结果及请求、正式CalBench；对齐Q0、旧D53、新D72/D148，并加入本地runs/diagnostic/new-bp99-v6s-biinv-v1-870333。六模型诊断manifest/runtime哈希和temperature/repeats/max_tokens等字段一致。旧BP99两次strengthened-v6逐行results完全相等。所有正式CalBench frozen_manifest完全相等，均记录batch-invariant；不把12局历史评测当24局复现。跨硬件数值一致性和跨独立训练seed泛化仍未证明。

每模型96诊断行是32case×3重复，16结构；表格去除重复。pairwise regret在同条件、同case共同合法集合上重算，再对结构等权。交集减少及选择偏差保留，另外给全部32case的精确正确数/合法数，非法不当成功。0.1容差下正确数与精确正确数相同。

## 诊断中的“格式失败”需正确理解

对旧BP99/D72/D148，逐一检查replica0三个行动条件全部非法回答：分别23/22/11个，均发出了单个工具调用，参数不在请求工具schema声明的合法参数enum中。它们不是纯文本JSON包装失败。实例binary-20908:voluntary的旧BP99，在正确B下把目标Workshop放进partner_commitments，而Blair可新增的承诺只有Maple/Willow。目标与承诺混淆是明确的执行/状态表示错误，不能归到B错误，也不能轻率放宽parser算对。

该诊断混合测量：证据到B、给定B的状态与收益计算、合法工具执行；更完整的交互还含沟通对象、多人行动一致性、反馈后的重规划。它不是CalBench替代指标。当前未发现这批差异由汇总错算造成，尚未穷尽审计全部teacher。历史误差和合理难度不等于诊断失效。

## 训练方面能排除与不能排除的解释

新D两段总592组/任务，实际有效O312、B177、P372组，不是没有任务学习信号。P masked211/4736回答，不能称P大部分被屏蔽。LR实际1e-6降至2.01e-7。近分布静态B宏准确率Q0 .352、60更新 .806、140更新 .620；同协议外部诊断B低，方向支持接口/结构泛化不足，训练内验证噪声和非同题差异使其不能作为严格效应量。

这些只排除“完全没有信号/根本没降LR”的解释，不排除优化干扰或错误数据分布；也不能证明更新次数是旧优势根因。数据接口、任务比例、曝光、优化、硬件并未被单变量控制。最终指标相同或不同都不能反推出唯一原因。

## 结论与真正缺少的信息

1. 旧BP99是一个有行动提升证据的checkpoint，不宜说它只是一次评测运气；其可重复训练性尚未证明。
2. 它没有展示稳健显式B及B修复收益，不能作belief→planning机制成功的正对照。
3. 新D有局部学习，却没有学出稳定的条件性决策/完整交互优势；诊断和CalBench不完全排序一致是测量构念不同的证据，不自动证明某个bench错误。
4. 现有对照可分解失败位置，但不能从多变量改变的训练链识别数据与优化的独立因果贡献；不再据此建议下一轮配方。
5. 优先补已有而非重跑的证据：相同frozen24协议的Q0结果与运行元数据，确认旧BP相对Q0的外部效应；旧BP99邻近/后续checkpoint在同协议下的结果（若仍有权重再考虑评测，不请求新训练），区分宽泛有效阶段与局部峰值。旧SP同期的同协议结果若已有，也可辅助判断非分解训练是否同样受益。单靠这一批权重的日志不能证明跨seed稳定性。
