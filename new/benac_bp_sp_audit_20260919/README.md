# B/P-only 与 self-play 的独立审查

本报告只比较 Q0、B/P step139、self-play step69。完整局回放和运行一致性检查见 `../benac_a_audit_20260919/README.md`。当前工作是评测轨迹与本地训练包的对应审查，没有改训练集、奖励、提示或模型。

## 证据边界

- 可确认：固定场景与座位下的收益变化、谁的调用直接终止游戏、模型实际动作、显式说明与可见事实是否一致、本地训练题的输入/评分结构。
- 不能确认：B 单独准确率是否提高（A 没有调用 B 问答）、正确说出某个 belief 是否因果性地驱动动作、当前轨迹差异由哪个梯度更新造成。
- 本地对应训练包是 `examples/social_mixed/data_binary_linear_v3`。尚缺 step139/step69 对应训练运行的完整 resolved config、采样/advantage 日志和数据指纹，不能把旧 `selfplay-853824` 的两步日志当 step69 训练过程。数据内容的审查结果成立，实际远端使用这一版本仍应由训练记录确认。
- B/P-only 用同一组模型权重分别接受 B/P 题的答案奖励；不是两个独立网络，也不是已经训练了一个强制 B→P 工具流水线。当前奖励校验最终 belief/动作，不验证说明文本的每一个中间推断。

## 未完成局的直接原因

|模型|完成|由 focal 终止|由固定 Q0 终止|基础设施错误|
|---|---:|---:|---:|---:|
|Q0|44/48|2|2|0|
|B/P|40/48|4|4|0|
|SP|38/48|5|5|0|

B/P 的四局 focal 失败全部为：首次输出到 1024 token 被截断，重试虽然生成了工具调用，却再次提交已绑定承诺。SP 的五局 focal 失败全部为：首答与重试都到 1024 token 被截断。Q0 对手的失败也是真正的模型协议失败，不是 HTTP/服务器错误。

这是“最后哪个调用直接阻断了运行”的归因，不是对整个交互的因果归责。不能把对手失败都算作被测模型不会使用工具，也不能删除这些局后只报幸存者收益。不同 focal 引发不同历史，固定 Q0 在不同历史上的表现也不同。

## B/P-only：有局部 P 改善，不能据此声称 B 全面改善

正常结束的局里，B/P 的 ID 自身 utility 0.254（19/24 局），OOD 0.333（21/24）；Q0 分别是 0.288（22/24）、0.068（22/24）。双方同一场景座位都完成的 OOD 19 对中，B/P 减 Q0 平均 +0.140，6 胜、8 平、5 负。另外 B/P 单独完成2局、Q0单独完成3局。证据有希望，但覆盖有限并有策略相关缺失。

### 相同决策输入上的具体改善

`A-OOD-linear-4r-avoid_heavy-seat1`，双方第2次全局调用有完全相同的 messages、tools 和 seed。Blair want Orchard/Harbor、avoid Library，面对 Alex.Maple + Blair.Maple 的 offer。

- 该动作使 Blair 的 Orchard 增加 1/2、Harbor 增加 1/3，不增加 Library，直接自身收益 +5/6。
- B/P ACCEPT；Q0 REJECT。
- B/P 的说明识别了想要目标的收益与没有增加避免目标；局部用词仍不完全精确。

这是较干净的已知状态与自身效用判断改善，和 P1 的训练目标相符。它不是行为似然推断的证据，也不等于整局最优策略证明。

### 仍未掌握的部分

1. 部分说明把目标依赖表中的 Cedar/Maple 当成别人“喜欢什么”。公开要求与私有偏好仍会混淆。
2. 已知偏好也未稳定接入依赖计算：知道伙伴 avoid 某目标，仍可能说某承诺不会影响它，尽管依赖表明确相反。
3. 已绑定承诺维护与重试修复没有稳定迁移：B/P 五次非截断非法调用涉及已绑定承诺，其中四次是导致终止的重试。
4. 调查后保持/使用信息不稳定：34次合法调查中，26次之后还有合法 focal 动作；其余8次可能因截止、其他玩家或自身失败而没有后续动作，不能统一解释为“调查无用”。另有3次调查发生在最后一个全局提案机会，无后续决策可受益；这不证明该状态存在严格更优动作，但不支持可靠的 deadline 信息价值判断。

## B→P 是否已经关联？

已有局部结果利用的迹象，但没有稳定闭合，更没有因果机制证明。

正例：`A-OOD-linear-4r-avoid_heavy-seat0`，B/P L1调查 Blair/Orchard=want，L9明确引用这一私有结果，并提议 Blair 新增 Maple、自身不新增。它提高了双方想要目标的完成比例，L10被接受。之后的行动仍使最终自身收益回到0，因此不能拿这个片段声称整局推理正确。此例检验的是调查真值→动作，不是行为证据→belief→动作。

反例1：`A-ID-linear-4r-balanced-seat2` L15。B/P 正确记得调查显示 Blair avoid Library，先说应避免给 Blair 加 Maple，随后又声称“Maple 是给 Orchard 的，不会触发 Library”，最终确实要求 Blair 新增 Maple。实际 Blair.Maple 同时参与三个 linear 目标，包括 Library。正确的伙伴事实被错误的环境效用模型抵消了。完整片段见原始 calls.jsonl L15。

反例2：`A-OOD-binary-4r-balanced-seat2` L8。B/P 正确记得 Blair avoid Harbor，却因此宣称 Harbor 不可能完成，尽管 Blair 对 Harbor 所需的 Maple 已经绑定，不再需要再次征得 Blair 同意。它把“伙伴不愿推动该目标”错误等同于“目标无法实现”。

目前 A 不包含独立 B 问答，也不能把 Q0 的自然轨迹套进理性 teacher 得到正确 posterior。因此不能量化“B 学会了多少”；更不能将 P/收益提升反推为 B→P 已连通。

## 本地训练数据为什么可能难以支持组合迁移

本地训练包426题：B 214、P 212，108个 origin_id（不是108个独立几何）。其中398题双人、28题三人；全部P4为双人。公开尚未固定的偏好槽最多2个，而A的三人局起始有6个伙伴偏好槽未知。A没有直接提供正确当前belief。

|内核|题数|重点接口|限制|
|---|---:|---|---|
|B1|104|belief形成|全部双人，主要1个未知槽|
|B2|52|belief形成的相关情形|三人12题，其余双人|
|B3|58|更新/保持|提供正确previous belief；不要求携带自己先前可能错误的判断|
|P1|72|已知偏好/当前belief下规划|仅4题有已绑定承诺|
|P2|56|给定联合belief下规划|仅8题有已绑定承诺；48/56自身所有目标都是want|
|P3|24|定性belief/范围下规划|全部双人，自身所有目标都是want；0题已有绑定|
|P4|60|调查价值/结果利用|全部双人；20题答案利用；仅8题已有绑定|

212道P题都带 supplied_belief 输入；P3另给定性范围，不能把“存在这个字段”误读成每题都展示完整数值posterior。仅20/212道P题的current_state有非零绑定；P1–P3都没有voluntary_history，P4只有20题有这类历史。P4中40题明确声明不存在额外行为似然更新，其余20为调查结果利用。

由此可见，B与P在内容上有关联，但评分通常分别问：在指定teacher和较充分公开事实下判断偏好；拿到准备好的belief后选择动作。当前数据很少直接奖励“从原始历史自行推断→据此选择动作→收到反馈后继续行动”。这不是说分开训练一定无法组合，而是目前组合泛化主要靠模型自行完成。

训练集不是完全没有avoid、deadline、共享承诺或调查结果题。问题是这些要素在多未知、多玩家、已有承诺和连续反馈的同一局中联合出现得少，不能用继续加改名变体来补。

## SP：更有形成承诺、推进任务的倾向，伙伴模型仍不可靠

SP的ID自身utility 0.525（20/24），OOD -0.019（18/24）；主要亮点是ID binary，已完成10/12局均值0.8，而Q0是11/12、0.273。与Q0共同完成的18个ID配对平均差+0.176，5胜8平5负；不是普遍逐局胜出。

合法提案决策中，SP OFFER 54/126=42.9%，Q0 48/139=34.5%；调查25.4% vs30.9%，PASS31.7% vs34.5%。这与减少部分不行动/调查、更多尝试形成承诺相符，但不同历史与机会分布不允许将比例差直接当策略最优性的证明。

正例：`A-ID-binary-4r-avoid_heavy-seat0`。SP先调查 Blair/Harbor，随后 L4 以 Alex.Cedar+Blair.Maple 推进共同目标，后续第三人加入；L12再新增 Alex.Maple 补上另一目标，最后3个want目标全达成，自身收益3，Q0同场景座位收益1。表现体现了跨多轮累积承诺的潜力。说明中仍混淆调查主体、推断其他玩家偏好和部分目标要求，且中间拒绝过有利推进，不是全程正确推理。

反例：`A-ID-linear-2r-balanced-seat1`，SP自身全部目标want，却在L4拒绝Casey.Maple+Blair.Maple；说明将未来还可添加Cedar误当成当前接受Maple会失去的机会，随后L6又主动提出双方新增Maple。同局最终收益2并不意味着中间决策合理，Q0后续承诺也贡献了收益。

没有看到“只有细粒度监督才会使用调查结果”的证据：SP也会调查并在后续提案中引用结果。反过来，SP仍会把依赖关系当偏好、不正确地赋予承诺单一目标含义。可观察到的是行动倾向与局部协调收益变化，不能据此声称学出了可靠的行为贝叶斯推断。

输出方面，SP平均501.7 token/调用，Q0 451.6；不是通过更短推理换来推进。SP截断25/189、Q0 41/234，比例有所降低，但SP有5局连续两次截断。全局奖励没有自动解决输出在有限预算内稳定落到动作的问题。

## 有依据的训练改进方向，尚未实施

B/P优先：保留单项题，同时加入少量原始历史→动作的组合对照；同一结构下配对不同伙伴证据/调查结果，并使正确动作随证据改变。可以在不同采样中分别问belief和动作，不要求线上强制两次工具调用。奖励不能仅确认模型复述了正确belief，还要确认最终动作利用了它。

内容优先：多目标共享承诺、want/avoid同时受影响、已有绑定状态、伙伴已经作出不可撤回承诺、一个伙伴的一次回应不等于完整偏好、自己掌握与别人掌握的私有结果边界。将它们放入同一三人连续决策结构，而不是只改变名字。

SP优先：检查完整局奖励是否主要支持易达成的正向合作结构；保留会惩罚错误承诺的冲突世界，并设计需要反馈修正的结构。不要奖励调查次数、解释长度或合作次数本身。必须用实际训练日志检查这些场景是否产生有效组内差异，再决定curriculum/采样/奖励修改。

针对两者的共同障碍：将截断与动作错误分开；单纯提高token上限可能恢复一部分局，但不是训练有效性的证明，也不是这次审查已执行的修改。

更强的B→P证据需要同一历史上的受控决策对照：原始历史、只补确定性状态事实、再补同信息下正确信念；不能给隐藏真值，也不能对任意Q0行为套理性teacher。优先使用已知对手模型、信息摘要足够支持决策的小局。这是之后验证组合的具体办法，不代表现在已经有结果。
