# B/P 诊断修订草案

状态：实验设计，尚未抽题或运行。旧 MENU/强制 B→P 工具流水线结果不能直接代表当前原生策略。

## 主张

检验伙伴推断 B、条件规划 P 是否存在可重复且有决策影响的缺陷，以及两者能否在同一历史上组合。诊断不证明 B/P 穷尽 social reasoning，也不预设 trained 必然优于 base。

## 三个问题与双向过程

1. 单项缺陷：B 在明确对手行为假设下是否正确保留/缩小不确定性？P 在获得信息匹配、决策充分的正确 belief 时是否能选择高价值动作？
2. 决策相关性：改变伙伴证据是否在应改变动作时改变动作，在不影响动作时保持选择？给正确 belief 的改善与无关辅助信息对照区分，避免将额外提示的一般帮助当成社会推断效果。
3. 组合过程：
   - B→P：同一历史上独立测 B、P_gold、P_infer，观察单项判断、给定 belief 规划、自行推断规划之间的缺口；B 答案不强制传入主决策调用。独立调用的差异不能证明模型内部因果中介。
   - 伙伴规划→B（逆向规划）：构造伙伴相同行动、但备选动作/机会成本不同的配对历史。在公开且明确的 teacher 模型下重新求解似然，检查模型是否因规划条件变化而合理改变偏好判断。加入行为不具有诊断性的对照。若提供规划辅助，只提供各偏好假设下的行动后果/策略似然，不给 posterior 答案；由模型结合先验和历史更新。
   - 自身 P→未来 B（主动取证）：这是另一种依赖，不能用逆向规划结果替代。当前只用原生 INVESTIGATE 检查值得调查/不值得调查/最后机会，以及获得结果后的判断与行动利用。不恢复 OFFER 信息获取或 MENU；不声称已经验证一般交互性取证。

完整过程可以是：理解伙伴为何这样行动 → 更新 belief → 按 belief 规划；或决定是否调查 → 得到观察 → 更新 belief → 决策。两者须分别命名和评分。

## 取题与比较

可以复用开发集的 binary/linear 小局及同机制新题，优先减少新环境工程。按机制和正反对照预先抽取题目，记录训练精确重复/同结构/未见结构来源，并冻结题目与评分。先检查 B 摘要的决策充分性；不能用丢失关键权重/相关性的语义摘要冒充完整 oracle。

同一冻结题组比较 Q0、B/P-only、SP-only。报告全部题目、分项正确率、动作 regret、协议失败以及 base→trained 的四种转移：错→对、对→错、均对、均错。不能先筛 base 错且 trained 对再作为总体证据。这样的例子仅可在全量结果之后作定性说明。

开发集结果用于机制诊断，不称泛化证据。训练集题目可作为学会监督目标的检查，必须独立标注。训练后仍错误或退步也必须报告。未做 B-only/P-only 训练消融时，不将训练收益归因于某一个训练组件。

## 所需证据的边界

oracle belief 修复动作，是该信息在受控条件下具有决策价值的证据；不是内部机制证明。伙伴规划条件改变推断，是逆向规划敏感性的证据；依赖指定行为模型。A 的固定伙伴完整局和 CalBench 同质团队迁移提供外部表现证据，不单凭收益提升判定 B/P 已耦合。
