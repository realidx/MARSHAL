# Strategic game slices：研究讨论 checkpoint（2026-10-01）

> **新对话从这里开始：**我们正在重新设计 MARSHAL/BENAC 的训练数据。核心主张是**筛选决策会产生不同后果的游戏片段**，再检验这种数据是否比完整对局 self-play 更有效。本文记录当前共识、数学定义、已有 pilot 和尚未确定的实验细节。`paper/experiment.tex` 目前仍描述旧实验，不代表下文方案已经实施。

## 1. 研究目标与边界

- **Game slice 首先是博弈对象。**它由原游戏中的可达入口、玩家能观察到的信息、一个有限决策窗口，以及窗口外的延续规则确定。它不必是可脱离原游戏独立求解的严格 subgame，也不必从父游戏根节点开始。
- 我们想筛选的基本性质是**决策后果**：在同一评价规则下，玩家可采取的策略带来不同的预期终局效用。行动数、搜索深度、文字推理长度和模型当前是否会犯错，都不能单独定义一个 slice 是否有决策后果。
- **Inference 和 planning 是解释 slice 中需求的视角，不是 slice 的定义来源。**不预先宣称 C 就是 planning regret、S 就是 inference regret；这两种能力分解本身尚未成为完整、标准的博弈论建模。需要做干净的能力诊断时，可以设计独立入口或受控信息对照，但不应以“可完美分离能力”为所有 slice 的准入条件。
- 井字棋是用于验证概念和测量流程的辅助实验；最终要研究的是我们自己的 2/3 人 BENAC 类游戏。BENAC 通常是 **mixed incentive**，不能当作零和博弈。
- 更强的论文主张应是“基于反事实决策后果筛选训练数据”，而不是声称我们发现了唯一或完整的“战略意图”度量。训练带来何种推理机制、能否迁移，仍需另外用实验证明。

## 2. Slice 的数学对象

令父游戏为有限扩展式游戏 $G$，焦点玩家为 $i$。一个候选 slice $s$ 至少固定：

1. **入口**：可达的玩家信息集 $I_s$，含其公共历史、玩家自己的私有观察，以及对与该信息集一致的隐藏世界的入口信念 $\mu_s$。不能把单个隐藏世界节点的真实状态直接交给模型。若从父游戏内部抽样入口，必须说明生成该历史的到达策略或外生设定，否则 $\mu_s$ 不唯一。
2. **决策窗口**：从入口开始，玩家 $i$ 在实际到达的分支上最多控制接下来的 $k$ 次自身决策。游戏提前终止时窗口自然结束。$k$ 不是固定游戏步数；其他玩家的行动可以发生在其中。
3. **窗口外规则**：其他玩家在所有分支上的参考策略、焦点玩家离开窗口后的参考策略、游戏转移和终局效用。所有被比较的窗口策略使用相同的规则。
4. **评价基准**：所用 oracle / 参考解的选择、效用尺度和求解精度。对双人零和游戏可以指定 minimax；对一般和多人游戏必须明确选定策略剖面、最佳响应或其他解概念。当前 BENAC pilot 用一个经检查的参考策略剖面，并固定对手策略；这**不**等于证明存在唯一均衡。

设 $\Pi_s$ 为窗口内合法、随观察而变化的策略集合，$J_s(\pi)$ 为在上述入口信念和延续规则下的焦点玩家预期终局效用。定义

$$
V_s^*=\max_{\pi\in\Pi_s}J_s(\pi),\qquad
C_s(\pi)=V_s^*-J_s(\pi)\ge 0.
$$

$C_s$ 是**策略的反事实 regret 函数**。若需要给 slice 一个与模型无关的筛选标量，可用

$$
C_{\mathrm{span}}(s)=\max_{\pi\in\Pi_s}C_s(\pi)
=V_s^*-\min_{\pi\in\Pi_s}J_s(\pi).
$$

在完全枚举不可行时，可用事先固定的探测策略提供**下界或筛选线索**，但不能把探测值冒充精确 $C_{\mathrm{span}}$。在单次决策且固定延续策略的情形，令 $Q_s(a)$ 是强制采取行动 $a$ 后的预期价值，则 $C_s(a)=\max_bQ_s(b)-Q_s(a)$。

连续 slice 的 $J_s(\pi)$ 必须沿 **$\pi$ 第一次行动真实到达的分支**计算第二次及后续决策；不能把模型的后续动作压到预录的 oracle 分支上求和。这样单点 $k=1$ 与多点 $k>1$ 使用的是同一个定义。

严格说，C 也不是脱离边界条件的“游戏固有常数”：它依赖入口信念、效用、对手和出口规则、求解概念。其一般性在于这些条件一旦确定，反事实决策差异既适用于完美信息，也适用于不完美信息、零和及一般和游戏。除另行注明 mask 对照外，C 与 D 默认在完整可用信息条件下计算。若不同父游戏效用尺度不同，跨游戏筛选/排名还需预先确定归一化方式。

## 3. S：指定信息的价值，不是另一种普遍 regret

对窗口内可能被焦点玩家使用的**指定信息** $Z$，保持同一物理游戏、入口分布、对手策略和窗口外规则，只改变玩家能否在窗口内看到 $Z$。令 full 和 mask 表示这两个信息条件，则

$$
S_s(Z)=V_s^*(\text{full }Z)-V_s^*(\text{mask }Z).
$$

当 mask 仅降低玩家可用的信息，且不改变其他人的行为规则时，可用策略集合包含关系保证 $S_s(Z)\ge0$。它衡量**这条信息在该决策窗口中的增量决策价值**。信息对照要在 $Z$ 揭示前固定共同的隐藏世界分布，或明确一个覆盖不同 $Z$ 实现的信息集集合；不能只取“已经知道 $Z$ 的单个信息集”并沿用其条件信念来遮蔽 $Z$。BENAC pilot 目前只对一项私有调查答案做精确遮蔽：公共行动树、调查成本和对手策略保持一致。对公共历史信息直接遮蔽会牵涉对手所见及信念，需另外定义干预，不能直接套用现有数值。

Pilot 同时报告自由选择初始行动的 $S$，以及两组都强制先调查的 $S_{\text{given query}}$。后者为正仅表示“已经调查后，答案可用于提高价值”，不表示**购买调查本身**最优。若窗口只含调查动作，答案可能在窗口外才被参考策略利用，因此窗口内 $S=0$ 也不能解释为答案在完整游戏中无价值。

$S=0$ 不表示模型一定能维持正确的 belief，也不表示题目容易。无价值但看似相关的信息仍可能干扰模型，故可以保留 **零信息价值控制题**。多个信号也可能互补，逐条 $S(Z)$ 不能自动相加。S 是对不完美信息中特定信息机制的补充刻画；**筛选 consequential slice 不要求 S 必须为正**。若某项 $S>0$，则在相同评价窗口中必有可用信息导致行动价值差异，但单独的 C 标量并不说明差异源于哪条信息。

## 4. D：当前模型的预期 regret

令 $\pi_{M,s}$ 为模型 $M$ 在该入口、提示、解码设定和真实可达分支上诱导的窗口策略，定义

$$
D_M(s)=C_s(\pi_{M,s})=V_s^*-J_s(\pi_{M,s}).
$$

在单点、固定对手和线性行动分布的条件下，

$$
D_M(s)=\sum_{a\in\mathcal A(I_s)}p_M(a\mid I_s)C_s(a).
$$

这正是“模型选择各行动的概率 × 各行动的 oracle regret”的总和；不需要再把 C 与 D 相乘。早先讨论中的 $C\times D$ 只是一种粗略口头记法，**不是现在的正式定义**。连续窗口仍用上一节的 $V_s^*-J_s(\pi_M)$，并在模型实际到达的分支上估计。若评价者会针对模型的整套混合策略重新博弈，单点加权公式未必成立，须回到 $J_s$ 的完整定义。

D 随模型 checkpoint、prompt 和解码方式改变。它说明**当前模型在哪些已定义 slice 上损失价值**，可用于课程/采样分配，也可跟踪训练进展；它不是 slice 是否“strategic”的定义。失效、非法行动、输出截断、reasoning loop 和传输失败要单独计数；除非实验事先规定了合法的游戏结果映射，不能给这些输出臆造终局 regret。仅在成功轨迹上计算的 D 必须同时报告完成率。

## 5. Slice 的筛选与长度

目前原则：**先用模型无关的 C 认定存在值得学习的行动后果；用 S 做信息价值分层与控制；再用初始模型 $D_0$ 分配训练注意力。**这三者不能压成一个声称普适的“战略性程度”。例如一个只有两个行动但错招损失很大的局面，与一个许多行动但价值差距较小的局面，没有无需任务目标的唯一难度排序；C 是损失尺度，D 是特定模型行为，而行动数及价值分布可另外报告。

窗口长度 $k$ 不能只看根节点。一处入口的第一步行动可能价值相同，但第二步实际到达的决策会造成损失。可先为每个入口计算 $k=1,2,3,\ldots$ 的有限候选曲线，并记录 $C_{\mathrm{span}}$、固定探测策略的 regret 增量，以及指定信息 $S_s(Z)$ 首次为正的窗口。优先选**能展示新增决策后果或信息利用的较短窗口**，保留部分较长窗口考察连续策略。具体最大 $k$、阈值、重叠窗口去重与配额尚未确定。不能因为长窗口更深，就默认它更有策略性。

一个带多次行动的 slice 与父游戏的关系是条件性的：它使用原游戏的隐藏世界、对手与终局效用，并定义一个清楚的入口和出口。它不必是严格 subgame，但必须让同一个模型策略在所有可达分支上都能执行和评分。

## 6. 已有证据：只到 pilot，不是正式训练结果

### 井字棋诊断

`new/tictactoe_slice_pilot/` 枚举了完美信息小博弈的单点行动价值，并用**未经过本研究训练**的 Qwen3-4B-Instruct-2507 测量过初始策略。1024-token 条件的 2048 次请求中，1776 次给出合法行动，270 次输出截断（13.18%）；合法行动上的错误率为 39.47%。检查过的部分截断实例反复修正分析，表现出未能及时收束的 reasoning loop；不能据此把全部截断归为同一原因。这是训练需要改善的现象之一。此实验只验证测量方法，不能从井字棋推论最终 BENAC 效果。详情见 [井字棋结果](tictactoe_slice_pilot/RESULTS.md)。旧 README 标题中的 “C × D” 与本 checkpoint 的正式 D 记号不同。

### 双人 BENAC pilot

`new/benac_slice_pilot/` 在原生双人私有调查游戏中实现固定对手、窗口内 best response、C/S 精确计算及 D 的模型探测流程。已有 100 个**过去为 short-interaction 任务预选**的 O 根节点：100 个通过当前有限 oracle 检查，95 个根行动 $C_{\max}>0.1$；其余 5 个中有 4 个在后续窗口出现固定均匀探测策略 regret 增量 $>0.05$，故 **99/100 通过后果筛选**。最终只取 8 个是人为设置的诊断 panel 上限（四类各两例），绝非只有 8 个局面合格。100 个根节点仅覆盖 12 个游戏 family，这些数值不是随机生成游戏中的流行率。38 个有合法调查的根节点中，14 个所选答案在最长测试窗口有 $S>0.05$。

另外对种子 501–518 的 18 次原生生成做过小规模检查：6 个是三人局面，11 个遇到 solver cycle，只有 1 个双人根节点通过当前有限求解/树大小门槛。该节点根行动 C 平坦，均匀探测策略的 regret 在 $k=1,2,3$ 分别为 $0,0.254,0.554$。这说明单点根筛选会漏掉连续 slice；18 次尝试也不足以估计数据产率。具体流程见 [BENAC pilot](benac_slice_pilot/README.md)。

BENAC 的模型探测脚本已准备好，7 个单元测试通过；**仓库中还没有真实 BENAC 模型的 D 结果**。当前实现只支持从 O 根进入（既有根与 fresh 测试根），不支持任意中途信息集的正式数据生成，也没有执行下述 100 父游戏训练对照。

## 7. 下一版单一训练对照：当前提案

1. **父游戏池**：预先固定 100 个 2/3 人初始对局，记录生成种子、隐藏世界分布、玩家数、family 和 oracle 可求解性。两组训练使用同一批父游戏。完整 self-play (SP) 从这些初始对局开始；slice 组可在这些父游戏的**任意合格、可达的玩家信息集**进入。每个父游戏可有 $m_g=0,1,2,\ldots$ 个保留 slice；不要求“100 父游戏恰好对应 100 slice”。
2. **候选生成**：在每个父游戏中按事先指定的到达机制枚举或抽样信息集及入口信念；测试多个窗口长度；计算或有界估计 C，按信息种类计算 S，并去除高度重复的入口/重叠窗口。让 2/3 人局面、不同角色、不同 C 强度、正 S 和零 S 控制都有覆盖。不能让一个 family 占据大部分数据。
3. **初始模型诊断与课程**：在通过游戏属性筛选的候选上测 $D_0(s)$ 和输出有效率。$D_0$ 高的 slice 可获得更大采样概率，但仅按 D 贪心选题可能集中在模型始终给同一种错答、组内没有训练差异的题。需结合覆盖、响应多样性/可学习信号和采样不确定性。一个可审查的形式是先按 $P(g)=1/100$ 选父游戏，再以 $P(s\mid g)=q_g(s)$ 选其中 slice（前提是 $m_g>0$）。例如可令 $q_g(s)=(1-\alpha)/m_g+\alpha w_g(s)/\sum_{u\in S_g}w_g(u)$，其中 $S_g$ 是父游戏 $g$ 的保留 slice 集，正权重 $w_g>0$ 由预先规定的 $D_0$、覆盖及响应质量构成，$0\le\alpha\le1$；这只是待定方案，不是已执行算法。训练中 $D_t$ 可以作为观测量更新；若按 $D_t$ 改变采样，则已变成另一个需明确定义的自适应课程。
4. **一组主要比较**：相同基座模型、总生成响应 token 预算、优化设置和预先声明的父游戏抽样目标下，训练 slice 方法与完整对局 SP。slice 回答较短，因此同样 token 下可以反复访问更多 slice；SP 单次对局较长、同一个父游戏访问次数较少。这种差异正是待测的训练效率机制，不能强行要求同样访问次数又声称 token 相同。逐父游戏记录 token、抽样次数、完整对局次数、实际决策调用数、有效/截断响应数；单列 oracle 计算成本。
5. **主要结果**：在未见过的完整 2/3 人对局上比较终局效用和合法完成率，并报告随已用生成 token 变化的学习曲线；补充模型在不同 C/S slice 上的 D 变化。要固定评估游戏、对手条件、解码协议及不确定性估计。若目标还包括迁移，则另在未训练任务上测量，不能由游戏胜率直接推断。

这**一个训练对照**可以检验“整套 game-slice 数据与训练方案”在等 token 成本下是否优于完整 SP。它不能单独归因于 C/S 筛选、oracle 标签、较短回答或更高重复次数中的某一项；若论文声称单一机制的因果作用，仍需额外证据。现有 [论文实验段落](../paper/experiment.tex) 写的是旧版“100 slices、100 SP 初始配置、三个能力式 slice 变体、约 6M tokens”，且未规定父游戏一一共享；不要把它当作这项新实验已完成的记录。

## 8. 开始实施前必须定下的事项

- **100 父游戏如何形成**：直接先固定 100 个，还是先生成较大候选池后按可求解与覆盖条件冻结 100 个？若固定池中 $m_g=0$，如何保证两组的共同父游戏分布并如实报告覆盖？
- **入口分布**：任意中途信息集的到达策略、入口 posterior、外生重置与合法回放机制。哪些公共历史会携带“其他玩家已经获知什么”的信息？若做能力诊断，需要更受控的对照。
- **oracle**：三人一般和对局使用何种参考剖面或最佳响应定义，如何处理未收敛、循环或只获得界的实例；是否可扩到足够多的 family。
- **长度与配额**：最大 $k$、C/S 阈值、较短和较长窗口比例、同一父游戏内的去重、$m_g=0$ 的处理。Pilot 阈值只是工程初值，不是理论常数。
- **D 与训练信号**：模型探测次数、置信区间、非法/截断输出的单独统计、训练组内有效差异，以及 $q_g$ 的固定公式。对外发布前确认不同游戏效用单位的归一化。
- **对照预算**：固定哪一种生成 token 口径、父游戏级采样/配额、超预算尾部如何处理，及 SP 与 slice 各自的 oracle 计算成本。预注册主要评估指标和随机种子。

## 9. 给下一段对话的起点

> 请以 `new/strategic_game_slices_checkpoint_20261001.md` 为当前研究设计，先不要沿用 `paper/experiment.tex` 的旧 slice 定义。我们已确定 C 是在固定边界条件下的反事实决策后果，S 是指定信息的价值，D 是当前模型在 slice 上的预期 regret。现在最需要把“100 个共享 2/3 人父游戏、任意信息集入口、可变数量 slices、一次等生成 token 的 SP 对照”落实成可执行的数据生成与抽样协议；尤其先解决入口 posterior、三人 oracle、零 slice 父游戏和 D 如何进入固定采样权重。
