## 改进后的分层

分类基于这一次训练的观测，不称为Q0难度等级，也不是成功率驱动的在线采样器。

| 层 | 判定 | 设计用途 |
|---|---|---|
| 持续失败待审 | >=3次曝光，>=24次合法错误，从无正确 | 先查可推导性和前置操作，再决定拆解，不靠单纯加采样 |
| 观察到语义对比 | 至少2次曝光，存在同组正确与合法错误 | 保留作为可学习候选；不保证泛化或持续改善 |
| 多次观测全对待复查 | >=2次，全部回答正确且无masked/非法/截断 | 保持测试候选，不宣称已掌握或直接移出训练 |
| 单次／未见／其他 | 不足以上述判断 | 保留覆盖，不能因未知就判为简单或太难 |

分层优先级：持续失败→单次→有对比→多次全对→其他。当前P的59个不合格视图继续标为原有不合格，不能进入训练候选。所有候选pool仅含train；validation不迁入，也不用于按模型成败选题。旧题与当前validation同源的链接不授予混入旧题训练的权限。

旧P233题有重复曝光和语义对比，27题多次观测全对，4题持续失败；这不是统一加入旧题训练的清单。旧接口和现在不同，混入前还需重新审查split、可见信息与训练目标。

## 下一版数据的明确设计约束

1. **先证据、再难度。** 长期失败题先检查prompt是否足以导出gold，尤其singleton B的行为策略假设。不要给标签错误或隐含信息问题套“高难度”。
2. **难度拆解必须保持来源可追踪。** B从直接可见证据、一次行为排除到多事件更新；每个派生版本需独立证明gold，不能删去关键证据还保留原答案。
3. **按操作保留旧P优势。** 历史条件行动、调查结果利用、行动后果计算与提案/回应都进入覆盖表。历史操作放在O；P继续无历史、定性belief。若要复用旧混合接口，必须另立辅助视图，不隐含恢复到P。
4. **保持完整目标题。** 简化题与原题同一parent、同一split；易题进步不算原题掌握。不要只保留能产生reward差异的题。
5. **不再按小类无条件等额重复。** 后续采样方案需同时报告parent数、单题曝光、操作曝光与有效组，避免几道题垄断一个类别。但本版不设尚无证据的比例、不更改线上sampler。
6. **把学习与保持分开评判。** calls看反馈与错误，固定validation看未训练题；仍需无辅助行动和交互测试。当前calls不能证明参数遗忘或恢复。
