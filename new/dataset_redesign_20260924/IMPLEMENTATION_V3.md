# 原题内难度排序与全局曝光 v3

已接入reasoning训练采样；无新增辅助题、无中间答案，无B/O/P题文或teacher修改。结构排序不是实测难度证书，也不是已经生成了一套新难度题库。

## 规则

- 所有普通/关系槽位共用view+canonical曝光计数；未见或少见的题先于多见题。关系两端都处于全局最低曝光时才成对采样，否则用普通覆盖填槽。保留关系，不保证每步都有关系。
- P取消小类等次数硬配额。类别计数按合格题数归一后参与排序，单题覆盖优先，3题小类不再靠类别配额反复占位。
- 同曝光层内，按剩余决策机会、可见历史长度、目标数、共享承诺数、合法动作数和玩家数的结构向量排序。完整关系对优先会允许两端结构不同，不声称严格逐题单调难度。未来需要结合真实采样验证或调整这一代理。
- P不使用审计存储历史估计难度，不读取gold集合大小或当前正确率来决定难度，不恢复历史或数字belief输入。
- O/C也使用同一全局曝光选择器，保留其token边界收集方式；D保持每步4O+4B+4P，每题8回答。O/C原有固定锚点与强制关系槽位被替换，采样内容因此改变，但不偷偷改成D的固定96回答更新。
- 任务权重、标准差归一化、LR、KL、temperature、验证频率、checkpoint频率均未修改。calls新增结构difficulty元数据；有效曝光计数现在也记录O/C。
- 新版本global-frontier-structural-v3；O/C/D拒绝从旧采样状态静默续训。启动新阶段或采用另行审查的迁移方案。没有提交训练。
