# 围绕 BENAC-P 的 B/P 研究回顾

2026-09-08。方法回顾与设计讨论，不是冻结后的训练方案。
本轮只新增这份文档，不改游戏、伙伴 kernel、模型接口或训练实现。

## 1. 我们要建立的证据链

主线保持 **Diagnose → Post-train → Solve → Transfer**。
研究对象是部分信息多玩家互动中的 partner belief（B）和 partner-conditioned
planning（P），以及二者通过行动和证据相互影响的过程。

需要回答的研究问题：

1. 在角色、规则和 state grounding 正确的前提下，B 与 P 分别有什么缺陷，在哪些场景出现？
2. 对 B、P 或二者进行后训练，是否改善对应能力，而不仅是输出格式或训练伙伴上的分数？
3. 改善 B 是否帮助 P；改善行动选择是否改变后续证据及 B 的表现？这些作用何时存在、何时不存在？
4. 这些改善能否支持完整游戏表现，并迁移到未见结构、伙伴和其他环境？

这里的 Solve 阶段以更好的完整游戏决策和结果为目标，不预设必须求出全局最优或 Nash 均衡。
上述问题是待检验的研究目标，不是已成立的贡献或创新性声明。
有限文献回顾不能证明“前人从未研究 B/P 耦合”。

用户已明确的约束继续有效：原生多玩家、独立利益、不可逆 commitment、offer/menu、
主动 rational oracle partner；B 输出语义性的 want/neutral/avoid 可能集合；
P 接收公开 history/state 和伙伴判断并输出行动；允许 brief reasoning，
不要求模型输出概率、Q 或 plan variable。
更丰富的全员私有偏好配置是研究候选，不能为求解方便默默换成偏好绑定的二类型主任务。

可以讨论的实现选择包括 teacher 如何构建、oracle 的使用范围、近似监督的资格、
采集策略、SFT/RL 组合、伙伴池以及训练规模。文献不自动授权修改研究对象或接口。

## 2. 我们已有的证据与尚缺的证据

依据当前 `plan.md`、`native_endgame_diagnose.md` 及本轮对话：

- 最新正式模型运行停在角色理解预检；prompt 已修正，新的完整能力缺陷与修复效应尚未验证。
- 原 100 游戏审计证明小范围内可以生成并核验 B/P 标签；它也暴露了同值动作、空历史样本
  和 menu responder 示范覆盖问题。它不是模型改善或迁移证据。
- 40 个丰富配置实例的开发 pilot 验证了轨迹合法性与信息隔离，也记录了有限预算下的
  求解失败；没有建立可规模生产的全私有 B/P 监督，更没有证明丰富场景不可求解。

因此不能把“修复已证实有效”“B 比 P 不重要”“必须 outcome-only RL”写成结论。
目前也不需要宣布已经选择一种新的 MARL 算法。

## 3. 文献能帮助决定什么

### ToMnet：行为数据可以教伙伴模型，但行为预测不是我们的 B 定义

**论文证据。** ToMnet §2、§3 使用不同 agent 的行为轨迹学习预测后续行为，
并不假定所有 agent 都最优。其 observer 在实验中能看环境状态和动作；
§3.5 的显式 belief 目标来自 agent 的 belief readout，作者明确说明该 readout
不因果控制 agent policy。[Machine Theory of Mind，ICML 2018](https://proceedings.mlr.press/v80/rabinowitz18a/rabinowitz18a.pdf)

**可借鉴。** 将“可采集的行为监督”与“求解整个伙伴决策问题”分开；分别检验
对已知 population 和未见伙伴的适应。行为预测可成为辅助训练或评测候选。

**不能照搬。** observer 的信息权限不能自动给我们的 ego；未来行为是训练目标，
不能进入当前输入。准确预测一次行动不等于正确保留偏好不确定性；agent 的自报
belief 也不是偏好可能集合的 oracle。不能因此把主线改成被动 opponent prediction。

**仍需我们回答。** 辅助行为预测是否能改善语义 B，以及是否进一步改善 P。
若考虑加入它，需与同预算的 B/P 训练比较，不能仅以预测准确率验收。

### BAD：行动本身携带信息，但可解码性依赖公开的策略结构

**论文证据。** BAD §3 在 fully cooperative setting 中使用公共 belief，
公开抽样的 deterministic partial policy 决定私有观测如何映射到动作，
并参与 posterior 更新；大规模 Hanabi 实验采用因子化近似与采样。
[Bayesian Action Decoder，ICML 2019](https://arxiv.org/html/1811.01458v3)

**可借鉴。** 区分行动改变物理状态和行动携带证据这两种作用；检查一个动作在
不同隐藏情形下为何会被选中。小例子精确验证、较大游戏使用近似，是可讨论的分工。

**不能照搬。** BENAC-P 玩家利益独立，不能把全体 agent 当成共同优化一个团队目标；
也不能默认任意伙伴共享可公开查询的策略映射。论文中的 public belief/policy
是算法内部对象，不意味着我们的模型应该输出概率表或 plan variable。

**仍需我们回答。** 在独立利益、主动伙伴和 binding menu 下，哪些取证动作值得付出
承诺代价；哪些只是导致不同反应而没有实际决策价值。P→B 实验必须保留这个区别。

### SocialRL：终局 reward 与显式监督都可用，但其指标不能替换 B/P

**论文证据。** SocialRL §4–5 在谈判环境中采用终局 outcome reward，部分任务先 SFT
再 PPO，并报告跨环境迁移矩阵。§5.4 用真实私有偏好匹配率衡量 Infer、下一动作
预测衡量 Anticipate，蒸馏 GPT-5.2 的 Infer→Act→Anticipate traces；报告的能力—收益
关系是 checkpoint 间相关性。[SocialRL，2026 预印本](https://arxiv.org/html/2608.13787v1)

**可借鉴。** 将 outcome 优化与显式能力训练设为可比较的实验；按环境分别报告
迁移，保留负迁移。SFT 可以提供新行为示范，再观察 outcome 优化如何选择这些行为。

**不能照搬。** 真实偏好匹配率不等于 evidence-supported possibility set；
Anticipate 也不等于包含伙伴选择、延迟后果和不可逆承诺的完整 P。
其相关性不能证明 B 无用，也不能替代我们的判断替换和行动干预。
不据此要求我们使用同样的 reasoning scaffold、teacher、PPO 配方或多个训练环境。

**仍需我们回答。** 对我们的语义 B 做针对性训练是否有独立收益；这个收益如何依赖 P
能力和场景结构。Outcome-only RL 是待比较的方法，不是已经决定替代 B/P 监督的路线。

### ReBeL、Pluribus、DeepNash：限定精确求解的职责

**论文证据。** ReBeL 将公共 belief state、学习与搜索结合，其均衡保证限定在
双人零和。[ReBeL，NeurIPS 2020](https://arxiv.org/abs/2007.13544)
Pluribus 在六人扑克中通过 self-play 和搜索取得实证强表现，论文不声称其算法
具有双人零和之外的相同收敛保证。[Pluribus，Science 2019](https://doi.org/10.1126/science.aay2400)
DeepNash 在双人 Stratego 中采用不使用搜索的 self-play RL。
[DeepNash，Science 2022](https://arxiv.org/abs/2206.15378)

**可借鉴。** 训练不必从逐步精确最优答案开始；理论保证、近似方法和实证评测应分开说明。

**不能照搬。** 不把我们的目标改成 Nash 求解，不将两人零和保证推广到独立利益多玩家；
这些系统的成功也不构成单卡 4B 训练成本或迁移效果的保证。

### TERMS：保留诊断工具的价值，不把其 reference 当作训练先决条件

**论文证据。** TERMS 的附录 D/E 使用离散化 reference planning 和 oracle 信息干预，
研究谈判结果之外的缺陷来源。[TERMS-Bench，附录 D/E](https://arxiv.org/html/2605.13909v1)

**可借鉴。** 明确信息条件、reference 的定义，以及修正判断后决策是否改变。
**不能照搬。** 不把双边价格谈判或它的低维 latent-state 表示当成 BENAC-P 的要求，
也不因为 diagnostic reference 能在小范围求出，就要求它负责全部训练示范。

## 4. 回到我们的问题：监督信号必须按含义分开

| 信号 | 不求完整最优策略能否取得 | 在本研究中的资格 |
|---|---|---|
| 状态转移、合法性、实际终局收益 | 能，由 simulator 确定 | 可校验接口、提供 outcome；不能单独证明 B/P 改善 |
| 伙伴实际动作和后续行为 | 能，通过轨迹记录 | 可作预测目标；一次样本不等于完整行为分布 |
| 实际隐藏偏好 | 能，由生成过程记录 | 可作另一个隐变量预测目标；不是“历史已经排除其他类型”的证明 |
| B 的证据支持集合 | 需要先验和行为模型下的支持推断 | 对我们的语义 B 是直接监督；计算与模型假设都需审计 |
| 同信息条件下的较强行动示范 | 可来自 teacher 或近似规划 | 可讨论用于 SFT，但需要质量筛选，不能标为精确最优 |
| 给定 continuation 的行动收益估计 | 可用重复 rollout 估计 | 有统计误差与 continuation 依赖，不是全局 Q* |
| 精确最优行动/价值 | 仅可求解范围内可得 | 适合诊断、校验及部分示范，不必覆盖所有训练位置 |

这里的分工是本次回顾得到的设计分析，不是文献已经替 BENAC-P 验证的结论。

B 的精确性并不逻辑上要求伙伴全局最优：对一个明确、可计算的行为机制也能定义
正确 posterior/support。但若用简化伙伴换取标签易算，会改变 rational-partner
条件；应作为明确标记的辅助条件讨论，不能偷偷替换当前主实验。
采样时没见到某类型，不构成把它从 B 答案排除的证据。

使用全知状态计算真实 outcome 或作为独立的训练 target，与把它输入行动者是不同的事。
同样，teacher 看全知状态给出的最佳动作，不自动成为部分信息条件下可模仿的正确行动。
近似示范和 rollout 比较必须从合法的信息状态出发，维持与历史相容的隐藏情形；
不能固定一个实际 world 的全知最佳行动后，把标签称为 Bayesian planning。

## 5. 研究目标与训练实现分开决定

下面是讨论框架，不是现在开始执行的实验矩阵：

- **保留诊断锚点。** 在能校验的范围内保留 B、oracle-judgment-assisted P、B→P、P→B。
  P 仍可由完整 history 重新推断；判断替换没有收益不证明内部 B 不重要。
  行动改变证据同时也改变 commitments；终局收益差不自动证明信息中介。
- **允许训练信号异质。** B 的可靠标签、P 的合格示范、outcome 可以承担不同职责。
  是否需要辅助行为预测、是否加入 RL、何时使用近似 teacher，均待讨论。
- **使训练比较对应研究问题。** B-only、P-only、B+P 是能力训练候选对照；
  outcome-only 或混合 RL 是后续候选。必须区分训练预算、信息条件和 teacher 质量，
  不能把更多数据/更强 teacher 的效应直接归因于“B/P 耦合”。
- **独立检验迁移。** 在 BENAC-P 内先区分新源游戏、新结构、新伙伴，再检验 C2C 等环境。
  跨环境 outcome 改善本身不能证明同一个 B/P 机制在目标环境发挥作用；
  如需这项机制主张，还应有目标环境可适用的诊断或干预证据。

我们可以据文献重新审视精确 oracle 的使用范围，但没有理由因此放弃语义 B、
多玩家承诺结构或双向干预。反过来，也不应为了维护某个实现而让研究必须先求解整个游戏。

## 6. 冻结训练方案之前要共同决定的四个问题

1. **B 标签边界：**全员私有时，哪些局面仍能可靠产生语义可能集合；不足部分是暂不监督，
   还是增加明确区分的辅助预测任务？保持模型无需输出概率。
2. **P teacher 资格：**什么证据足以接受一条非最优性认证的示范；如何用小范围精确题
   和独立 rollout 检查 teacher 偏差？失败、同值与不确定样本如何保留和报告？
3. **伙伴分工：**固定 rational oracle 用于哪些训练/诊断环节；伙伴池或 self-play
   是否必要、何时引入？不预设所有训练伙伴都必须可精确反解，也不擅自取消现有 oracle。
4. **最低可行的证据链：**在单卡全参数 offload 小规模实验中，怎样先证明一次
   可归因的能力改善，再扩大样本与迁移评估？算力预算不能只算 optimizer，
   还要计入 teacher、伙伴 rollout 和评测调用。

下一步应先围绕这四项讨论，暂停批量扩充游戏和训练实现。
