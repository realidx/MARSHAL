# 13题与24题：结构和逐题学习对照

主链沿用 ANALYSIS.md。首次/末次各5次曝光，每格40个回答；不是Q0固定测试，不同实验对应更新区间不同。正确率分母包含截断及无效输出。

13题为P8/O2/B3，每题40次；24题为P8/O8/B8，每题20次。共享12题，24题移除55815…O并增加7O与5B。P题完全一致。等题权重意味着任务总权重也由8:2:3变为1:1:1。

结构核查：24题8个O的teacher.acceptable_actions交集为 OFFER(partner_id=1, proposer_action=[1,0], partner_action=[0,1])。这是内部动作编码；人物与工具呈现仍需映射。13题2个O交集为空。24题O有want/neutral/avoid和linear/binary变化，但不能据此称为必须改变行动的对照；want4题均linear，neutral2和avoid2均binary，变量混杂。

两版所有B均为possible_preferences=[want,neutral,avoid], favored=undetermined。B准确率上升不能单独证明证据条件推断能力。

两版均没有任何一道题在所有曝光中一直8/8全对或一直0/8全错。下面展示的是实际采样学习轨迹，不作因果能力认证。
