## 合法调用掩盖了哪些语义错误

以下是可追溯的实例，不是对96段reasoning的穷尽人工分类；不能由这些摘录推算各类错误的整体发生率。完整原文与对应冻结请求保存在 `evidence.jsonl`。

1. **把目标需求误读成伙伴偏好。** `binary_complementarity:preset:B`, replica 0，声称“Blair's known public preference for the Library is Cedar”。实际Cedar是承诺名；Library偏好没有公开。该组8次都输出全集但favored=want，强制行为并未提供这种偏好证据。

2. **把偏好当作目标是否完成的条件。** `binary_complementarity:preset:P_gold`, replica 1，声称伙伴want则Library完成，否则不完成。规则实际由绑定承诺决定完成度，偏好只决定个人收益。

3. **把每次新增上限当作整局承诺上限。** `binary_complementarity:voluntary:P_gold`, replica 0，先准确复述3/11 neutral、8/11 avoid，随后声称已有Maple所以不能再新增承诺。题面明确每次提案至多新增一个，不是整局只能有一个，不同承诺可同时成立。

4. **把最后一次提案理解为已无回应机会。** `mixed_partial_completion:preset:P_gold`, replica 2，声称最后一回合无法再有回应，因此任何offer都不能生效，选择PASS。规则明确一份提案连同回应构成一个机会，最后一次offer仍有回应并可绑定。

5. **知道没有后续动作，仍为信息本身调查。** `binary_complementarity:preset:P_gold`, replica 0，明确承认调查没有后续战略收益，又以减少不确定性为由选择调查。

这说明：本轮没有goal名填进commitment字段的格式失败，但不能据此说grounding已解决。全部64次P回答只有2次OFFER，对OFFER标识混淆的覆盖本来就很少；上述状态、规则和效用语义错误仍明确存在。

## 一项需要承认的题面混淆

`mixed_partial_completion:voluntary:P_gold`, replica 0，把调查称为“valuable for diagnostic clarity”。诊断题面包含“For this diagnostic”等用语，可能使模型把评测目的混入游戏目标。

这不是已证明的因果根因，也不能解释全部29次调查，但有具体回答证据，值得做中性措辞对照。当前输出已冻结，不能事后改题并把两轮成绩混在一起。应保留游戏规则及teacher约定，仅移除评测身份措辞，其他输入保持一致。

## 对B/P接口讨论的影响

此前接口审查成立：support/favored不足以覆盖所有P决策所需的信息，逐目标精确概率也可能丢相关性。

这次模型结果回答了另一个问题：**提供了决策充分的正确belief，也没有让模型在这几个状态上作出正确动作。** 所以当前不能通过增加B概率标签，期待直接解决这些P失败。

更准确的能力画像是：

- B的自愿行为判断尚未成功。
- P在正确belief下也未成功，受到调查偏好、规则/状态/效用理解错误的影响。
- 目前不足以隔离“已具备B和P，却不能组合”的故障；首先需要建立下游P能够工作的诊断条件。

## 建议的下一步

保持现有命名和冻结原题，先做小型对照，而非继续扩充B输出：

1. **中性措辞对照**：只移除diagnostic等评测身份用语，保持同一状态、工具、belief与规则。
2. **grounding-assisted P_gold**：在中性版本上提供准确的当前目标完成度、双方自身效用/新增承诺规则的状态解析；仍保留伙伴不确定性、回应预测和动作选择。不提供最佳动作或最终期望Q值。与中性版本单独比较，不同时改多个因素后归因。
3. 根据结果再做少量deadline正反例与有效OFFER题的训练能力检查，确认健康训练链路能否学会这些模式。训练集改善不能当作结构泛化。

本次没有修改题包或训练配置，也没有发起新模型调用。
