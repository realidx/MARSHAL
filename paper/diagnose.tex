\label{sec:diagnose}

Before training, we ask whether Qwen3-4B-Instruct-2507
\citep{qwen2025qwen3instruct} can infer a partner's
preference from interaction and use that inference to choose a valuable
action. A terminal outcome alone cannot locate a failure: the agent may
misread the partner, choose poorly despite a correct reading, or make errors
at both steps. Our diagnostic therefore measures inference and planning at
the same decision, then intervenes on the information passed between them.

\paragraph{Matched decisions and oracle labels.}
We select 16 two-player game structures, eight with binary goals and eight
with linear goals. Each yields two cases with the same displayed partner
actions, current commitments, legal actions, and payoff for every possible
partner preference. In one case the partner chose those actions under the
reference policy; in the other they were externally imposed. Only voluntary
actions are evidence about preference. The oracle thus assigns different
posteriors to the two cases although their current decision problems have
identical physical states.

For the queried partner--goal preference $v_{jg}$, we marginalize the oracle
posterior at the acting player's information set $I_c$ to obtain
$p_c(z)=\Pr(v_{jg}=z\mid I_c)$ for
$z\in\{\textsc{Want},\textsc{Neutral},\textsc{Avoid}\}$. The inference label
$J_c^\star$ contains every value with $p_c(z)>0$ and a favored value only
when its probability exceeds the runner-up by more than $0.1$; otherwise
the favored field is \textsc{Undetermined}. This is the qualitative judgment
the model is asked to produce and the only judgment supplied to controlled
planning; the numerical posterior stays in the scorer. For each legal action
$a$, the oracle separately computes its expected terminal utility
$V_c(a)=Q_i^\star(I_c,a)$ and the optimal-action set
$A_c^\star=\arg\max_a V_c(a)$. We retain a pair only when its two inference
labels differ and, for each label, every compatible posterior gives the same
optimal-action set; the two sets must be disjoint. Consequently, the evidence
distinction is consequential for choosing a high-value action, and the
qualitative label is sufficient to identify the optimal set under the fixed
reference continuation. Appendix~\ref{app:diagnose} gives the exact
certification procedure.

\paragraph{Replacing the inferred judgment.}
For each case, we first ask the base model to infer $\widehat J_c$ from the
visible history. We then ask it to choose an action in a fresh planning
context with either $\widehat J_c$ or the oracle label $J_c^\star$. The two
planning requests have identical rules, current state, legal actions, and
decoding settings; they contain no behavioral history, and differ only in
the supplied judgment. A separate native request asks for an action directly
from the history without an explicit judgment. We score every chosen action
against the same oracle posterior, using
\begin{equation}
 \operatorname{Reg}_c(a)=\max_{a'}V_c(a')-V_c(a),\qquad
 \Delta_c=V_c\!\left(\widehat a(J_c^\star)\right)
          -V_c\!\left(\widehat a(\widehat J_c)\right).
 \label{eq:diagnose-regret}
\end{equation}
Thus $\Delta_c$ is the paired effect of replacing the explicit inference
answer for this model planner; $\Delta_{\mathrm{repair}}$ denotes its mean
over valid pairs. It need not be positive: a planner can misuse
a correct judgment, and an inference error can accidentally offset a planning
error.

\paragraph{Base-model diagnosis.}
Table~\ref{tab:diagnose-main} reports the unchanged instruction-tuned
checkpoint. Exact inference
requires both the complete possible set and the favored field. The model
gets only $3/32$ judgments right, all in the imposed-action cases; it gets
none of the 16 voluntary cases right. Supplying the correct judgment does
not resolve action selection: only $2/32$ actions are optimal, with mean
regret $1.151$. The native history-to-action condition produces only two
optimal actions among 30 valid responses. These are failures of the evaluated interfaces
on selected diagnostic cases, rather than estimates of error rates over all
games.

The replacement nevertheless changes the model's action in $19/24$ valid
pairs: its choice depends on the supplied inference. Yet only three changes
improve utility, seven worsen it, and the average repair effect is negative.
Together with the certified change in optimal actions across matched cases,
this separates two claims: partner inference matters to the decision, but
correcting the explicit inference answer is insufficient when the model also
fails to plan from it. The intervention establishes dependence at the
judgment-to-action interface; it does not identify separate internal modules
or guarantee that inference repair alone improves end-to-end play.
