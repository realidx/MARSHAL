\label{sec:diagnose}

We next test whether an LLM can recover the partner state needed for a
decision ($B$), choose an effective interaction when that state is supplied
($P$), and compose the two. Final game reward alone cannot distinguish these
failures: a poor action may follow either a wrong judgment or poor use of a
correct one, while two errors may occasionally cancel.

\subsection{Matched semantic interventions}

We construct 16 held-out two-player structures, evenly divided between binary
and linear goals. Each structure yields a matched pair. In the
\emph{voluntary} case, the displayed partner actions are observations generated
by the fixed reference policy; in the \emph{preset} case, the same actions are
imposed interventions and hence provide no evidence about preference. The two
cases end at exactly the same physical state and have the same legal actions,
per-world payoff table, and fixed continuation policy. Changing evidential
status therefore changes only the posterior weights used to evaluate this
otherwise identical planning problem. Selection uses teacher quantities only.
In every pair, the correct semantic judgment changes. We retain a structure
only if, on each side, every posterior compatible with that semantic judgment
has the same exact optimal-action set, and the two invariant sets are
disjoint. Thus the deployed judgment is sufficient for the decision while the
inference difference remains decision-relevant.

The model-facing interface is the one used by our agent. For the single
unknown partner--goal preference, $B$ returns (i) the complete subset of
\textsc{Want}, \textsc{Neutral}, and \textsc{Avoid} that remains possible and
(ii) the uniquely most supported value, or \textsc{Undetermined}. It never
returns probabilities. We then query fresh planning contexts with either the
model judgment $\widehat B$ or the correct semantic judgment $B^\star$. These
controlled planning prompts retain the complete current decision state---the
binding commitments, remaining turns, investigation quota, legal actions, and
fixed continuation policy---but remove the behavioral chronology from which
$B$ was inferred. Before inserting the judgment, the voluntary and preset
planning requests are byte-identical. Thus the supplied judgment is the only
route by which their evidential distinction reaches $P$. A third condition
asks for a native history-to-action decision without an explicit judgment.
Exact posteriors and per-world payoffs remain in the backend and are used only
for scoring. Importantly, $B^\star$ denotes the correct deployed semantic
summary, not the full posterior. We certify its decision sufficiency by
decomposing the compatible posterior region into convex polytopes and exactly
enumerating their rational vertices. Since action values are affine in the
posterior, an identical optimal-action set at every vertex proves invariance
throughout the region. We conservatively include the closure of strict support
and favored-margin constraints. In an auxiliary condition on eight voluntary
structures, $B$ additionally receives a qualitative reference-planner
statement---e.g., that the observed sequence is impossible, more likely, or
less likely under each preference---but still receives no numerical belief.
This tests whether failures arise from modeling the partner's plan or from
subsequently integrating that behavioral evidence.

Let $F_c(a,\theta)$ be the certified payoff of legal action $a$ in case $c$
when the unknown preference is $\theta$, under the same fixed continuation,
and let $b_c^\star$ be the backend posterior. We score every action using
\begin{equation}
 V_c(a)=\sum_{\theta}b_c^\star(\theta)F_c(a,\theta),\qquad
 \operatorname{Reg}_c(a)=\max_{a'}V_c(a')-V_c(a).
 \label{eq:diagnose-regret}
\end{equation}
Thus an action prompted by an incorrect judgment is still evaluated in the
correct world distribution. We also measure the paired judgment-repair effect
\begin{equation}
 \Delta_B=V_c\!\left(\widehat a(B^\star)\right)
          -V_c\!\left(\widehat a(\widehat B)\right),
 \label{eq:diagnose-b-repair}
\end{equation}
using deterministic decoding so that the two calls differ only in the supplied
judgment. A positive value means that repairing $B$ improves this planner; it
is not an additive estimate of a standalone ``B error.'' Invalid tool outputs
are missing rather than replaced with a default action.

The structural rows establish that inference matters: changing only
evidential status changes the invariant optimum, with a nontrivial minimum
gap. They also close the interface ambiguity present in the previous suite.
Although the native summary omits probability magnitudes, those magnitudes
cannot change which actions are optimal in any retained case. Consequently,
regret under $B^\star$ measures planning after a sufficient deployed belief
interface is fixed, while $\Delta_B$ measures whether repairing that interface
changes the same planner's utility. The native history-to-action condition
still measures composition and cannot alone localize a failure. We will report
condition-specific means with their valid counts and use only doubly valid
paired records for repair identities.

\paragraph{Illustrative failure patterns.}
After the certified run, we will select one inference trace and one clean
planning trace from the frozen cases. The former must expose a concrete misuse
of voluntary versus imposed evidence; the latter must choose outside the
certified invariant optimal set despite receiving $B^\star$. This keeps the
examples illustrative without using them as substitutes for aggregate
evidence.
