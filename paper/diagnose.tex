\label{sec:diagnose}

We next test whether an LLM can infer the partner state needed for a
decision, plan an effective interaction when that state is supplied,
and compose the two. Final game reward alone cannot distinguish these
failures: a poor action may follow either a wrong judgment or poor use of a
correct one, while two errors may occasionally cancel.

\subsection{Matched semantic interventions}

We construct 16 held-out two-player structures, evenly divided between binary
and linear goals. Each structure yields a matched pair. In the
\emph{voluntary} case, the displayed partner actions are observations generated
by the fixed reference policy; in the \emph{preset} case, the same actions are
imposed interventions and hence provide no evidence about preference. The two
cases end at exactly the same physical state and have the same legal actions,
per-world payoff table, and fixed continuation policy. Changing evidential
status therefore changes only the posterior weights used to evaluate this
otherwise identical planning problem. Selection uses teacher quantities only.
In every pair, the correct semantic judgment changes. We retain a structure
only if, on each side, every posterior compatible with that semantic judgment
has the same exact optimal-action set, and the two invariant sets are
disjoint. Thus the deployed judgment is sufficient for the decision while the
inference difference remains decision-relevant.

The model-facing interface is the one used by our agent. For the single
unknown partner--goal preference, inference returns (i) the complete subset of
\textsc{Want}, \textsc{Neutral}, and \textsc{Avoid} that remains possible and
(ii) the uniquely most supported value, or \textsc{Undetermined}. It never
returns probabilities. Let $J$ denote this semantic judgment. We then query
fresh planning contexts with either the
model judgment $\widehat J$ or the correct semantic judgment $J^\star$. These
controlled planning prompts retain the complete current decision state---the
binding commitments, remaining turns, investigation quota, legal actions, and
fixed continuation policy---but remove the behavioral chronology from which
the judgment was inferred. Before inserting the judgment, the voluntary and preset
planning requests are byte-identical. Thus the supplied judgment is the only
route by which their evidential distinction reaches planning. A third condition
asks for a native history-to-action decision without an explicit judgment.
Exact posteriors and per-world payoffs remain in the backend and are used only
for scoring. Here $J^\star$ denotes the correct deployed semantic
summary, not the full posterior. We certify its decision sufficiency by
decomposing the compatible posterior region into convex polytopes and exactly
enumerating their rational vertices. Since action values are affine in the
posterior, an identical optimal-action set at every vertex proves invariance
throughout the region. We conservatively include the closure of strict support
and favored-margin constraints. In an auxiliary condition on eight voluntary
structures, the inference task additionally receives a qualitative reference-planner
statement---e.g., that the observed sequence is impossible, more likely, or
less likely under each preference---but still receives no numerical belief.
This tests whether failures arise from modeling the partner's plan or from
subsequently integrating that behavioral evidence.

Let $F_c(a,\theta)$ be the certified payoff of legal action $a$ in case $c$
when the unknown preference is $\theta$, under the same fixed continuation,
and let $b_c^\star$ be the backend posterior. We score every action using
\begin{equation}
 V_c(a)=\sum_{\theta}b_c^\star(\theta)F_c(a,\theta),\qquad
 \operatorname{Reg}_c(a)=\max_{a'}V_c(a')-V_c(a).
 \label{eq:diagnose-regret}
\end{equation}
Thus an action prompted by an incorrect judgment is still evaluated in the
correct world distribution. We also measure the paired judgment-repair effect
\begin{equation}
 \Delta_{\mathrm{repair}}=V_c\!\left(\widehat a(J^\star)\right)
          -V_c\!\left(\widehat a(\widehat J)\right),
 \label{eq:diagnose-repair}
\end{equation}
using deterministic decoding so that the two calls differ only in the supplied
judgment. A positive value means that repairing inference improves this planner; it
is not an additive estimate of a standalone inference error. Invalid tool outputs
are missing rather than replaced with a default action.

Both checkpoints fail to recover the voluntary evidence: neither produces one
exact judgment in 16 voluntary cases. Their five exact judgments occur only in
the preset half. The new model's possible-set gain also comes from preset cases
($16/16$ versus $14/16$); both score $0/16$ on voluntary possible sets.
Qualitative descriptions of the reference plan change no exact judgment.

Planning remains defective after inference is fixed. With the correct,
decision-sufficient $J^\star$, regret is positive on $19/25$ valid old-model
cases and $27/29$ new-model cases. Hence this failure cannot be attributed to
missing posterior magnitudes. The new model produces valid actions more often,
yet has higher regret. On the common valid subsets, correct-judgment regret is
$0.802$ versus $1.130$ over 24 cases spanning all 16 structures, while
end-to-end regret is $0.690$ versus $0.887$ over 28 cases and 14 structures.
Thus improved protocol compliance does not translate into better decisions.

Repair exposes the coupling between the two capabilities. Changing only the
semantic judgment changes the action in $7/16$ and $16/24$ paired cases, so the
planner does respond to inference; however, no repair improves utility. Three old and
six new cases become worse, while the rest are utility-equivalent. On the 14
cases (10 structures) valid for both checkpoints, mean repair is $-0.158$ and
$-0.550$, respectively. We interpret this as a misaligned belief-to-action
interface and error cancellation, not as evidence that the planner ignores
inference or as an additive decomposition of error.

\paragraph{Illustrative failure patterns.}
In \texttt{binary-20796:preset}, the new model conflates a goal's required
action with preference, calling Blair's Library preference ``publicly known''
and favoring \textsc{Want}; this wrong inference nevertheless elicits the certified
optimal offer. Replacing it with the correct \textsc{Undetermined} judgment
makes the same planner choose \textsc{Investigate}, despite stating that the
game ends after this turn, increasing regret from $0$ to $2$. This is a
recurrent opportunity-cost failure: under correct inference, all 7 old-model and all
14 new-model investigations have positive regret. The trace makes the negative
repair concrete: an inference error and a planning error can cancel.
